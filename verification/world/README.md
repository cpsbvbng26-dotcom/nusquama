# 各国の憲法と法令の調べ

ヌスクァマと Sophaxis が触れうる各国の条を、一次資料から取り寄せて記した場所です。
調べの記録（方法・数・当たる条と計画）は [docs/world-law-2026-11-12.md](../../docs/world-law-2026-11-12.md) にあります。
この調べは、弁護士の確認を受けていません。

## 範囲の決め

2026-11-12 に Claude が決めました。

- 国は、国際連合の加盟国 193 と、オブザーバー国家 2（聖座・パレスチナ）の 195 です。台湾・コソボなどは入れていません。どの国の一覧に拠るかで数が揺れないように、国連の地位で線を引きました。
- 憲法は、どの国も Constitute Project の英訳で読みます。195 の国の文を、同じ形で、機械で読める所在から取れるのはここだけだからです。英訳は公式の文ではないので、記録はその旨を断ります。日本だけは、e-Gov の日本語の文も読みます。
- 法令は、六法全書の全部ではなく、二つの場に関わる主題の条だけを探します。主題は、称号・栄典、主権と国家を装うこと、国のしるし、詐欺と誤認、個人データ、名誉毀損、引用の七つです。全部の条を記すと、リポジトリが大きくなり、読む人も当たる条を見つけられないためです。
- 日本は、憲法・民法・刑法・商法・民事訴訟法・刑事訴訟法の全文を取り寄せ、主題の語に当たる条を全部読みました。個人情報保護法・軽犯罪法・不正競争防止法・商標法・著作権法・消費者契約法・情報流通プラットフォーム対処法・国籍法も同じ形で読みました。
- 引用の例外は、日本の著作権法第32条とベルヌ条約の第10条だけを読みます。Sophaxis の引用は、運営の地の法である日本法と、載せる作品の CC BY 4.0 の許諾に拠り、各国の引用の例外には拠らないためです。ほかの国の行では、この主題を「対象外」と書きます。
- 法令の取り寄せ先は、公式の法令データベースか、条約の寄託先・公の機関の頁を先にします。公式の所在が機械に答えないときは、Internet Archive の写しを試します。公式でない写し（法情報機関の頁など）を使った出典は、`sources.json` の `official` の欄にその旨を書いています。

## 取り寄せ方

取り寄せは GitHub Actions の「各国の法令の取り寄せ」（`.github/workflows/world.yml`）が行います。
組は、`japan`・`shared`（複数の国に共通の法令）・`africa`・`americas`・`asia`・`europe`・`oceania` です。
`cons-地域` は憲法だけを、`codes-地域` は法令だけを取り寄せ直します。
組ごとに一つの実行で、要求は一つずつ、2.5 秒以上の間を空けて送ります。
User-Agent にはこのリポジトリの所在を書き、個人の情報は送りません。
組が終わるたびに、この枝へ記します。

## 当たった条の分け方

当たった条は、「当たる」「当たりうる」「当たらない」の三つに分けます。
分け方は二通りです。

- 一つずつ読んだ決め：日本の条と、各国の法令のうち称号・栄典の条などは、条を読んで決めました。決めには、決めたときの文の SHA-256 を添えています。文が変われば決めは外れ、検査が落ちます。
- 型の決め：憲法の条とデータ保護法の条の多くは、文の型（元首が栄典を授ける、国の領土は不可分、など）で分けました。型と理由は `decisions.json` の `rules` にあります。

型の決めは、条を一つずつ読んだものではありません。
「当たる」「当たりうる」の条のうち、重さが「高」「中」のものは、統合の段で一つずつ読み直します。

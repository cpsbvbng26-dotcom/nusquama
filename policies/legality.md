# 適法性の説明

最終更新：2026-11-13。

## この頁の位置づけ

この頁は、ヌスクァマが法令に触れないと運営者が考える理由を、法令ごとに並べたものです。
それぞれの法令について、当てはまるために要る事柄（要件）と、ヌスクァマの事実を並べ、要件に当たる事実がないことを示します。
あわせて、その事実を保つための決めが、どの規程のどこにあるかを示します。

この頁は、運営者の理解を書いたもので、法的な助言でも保証でもありません。
弁護士の確認は受けていません。
条文は要旨で書いており、文言そのものではありません。
要旨は、2026-11-08 に e-Gov 法令 API から取り寄せた現行の条文と突き合わせました。突き合わせた条は、各節の見出しに挙げています。
2026-11-12 に、この頁を条ごとに点検し直しました。点検で足した条は、各節の「点検で足したこと」に挙げ、同じ日に取り寄せて読みました。
点検の記録は[法令の点検の記録（2026-11-12）](https://github.com/cpsbvbng26-dotcom/nusquama/blob/main/docs/legal-audit-2026-11-12.md)にあります。
各節の終わりの「条文」には、文言そのものを引いています。
日本の条文は、e-Gov 法令 API から取り寄せて見張りに記した文を、手を入れずに引いています。
外国の条約・法令・説明は、それぞれを公開している頁から 2026-11-12 に取り寄せた文から引き、訳は付けていません。
法令や事実が変われば、この頁を改めます。

## 運営の姿勢

ヌスクァマに悪意はありません。人をだますことも、誰かを害することも、目的にしていません。
運営者は、日本の法令と、使っているサービスの規約を守って運営します。
法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します。
適法かどうか迷う事柄は、行わないほうを選びます。
この姿勢は、[利用規約](./terms.md)「悪意がないことと、法令を守ること」で約束しています。

## 前提となる事実

以下の説明は、次の事実の上に立っています。どれも、公開のリポジトリとサイトで確かめられます。

- 領土を持たず、どの土地の領有も主張しない。
- 国民・政府・軍・警察を持たない。
- 通貨・旅券・身分証・証明書を発行しない。
- お金や品物を受け取らない。何も売らず、寄付を受けず、広告を出さない。
- 勲章・徽章・制服などの物を作らず、配らない。
- 称号は、創作の中の言葉として、リポジトリとサイトと、王がこの国を紹介するために自ら書いた記事や投稿（README「ほかの場所」に挙げたもの）の中でだけ使う。
- 扱う個人情報は、GitHub のアカウント名と、本人が公開した訂正へのリンクと、本人が書いた説明だけ。リンクの先から本名や所属が分かることがあり、そのことを様式で知らせている。
- 誤りの知らせと求めの issue では、GitHub のアカウント名と、本人が書いたことを扱う。
- 16 歳未満の人と、住んでいる国の法令が私人の授ける騎士の称号を禁じている人の願い出は受けない。
- 国籍・年齢・住んでいる国・本名を確かめる書類を取らない。年齢・住んでいる国・願い出のときにいる国・国籍は、様式の誓いによる本人の申告で受ける。
- どの頁も、創作であり、実在の何とも関係がないと断っている。

## 法令ごとの整理

### 内乱に関する罪（刑法第77条）

- **要件の要旨**：国の統治機構を破壊し、またはその領土で国権を排除して権力を行使し、その他憲法の定める統治の基本秩序を壊乱することを目的として、暴動をすること。暴動の意味（多数の人が結び付いて暴行や脅迫をし、一地方の平穏を害する程度に至ること）は、条文にはなく、一般的な解釈による。
- **ヌスクァマの事実**：領土を持たず、日本や他国の統治や権力を排除しようとしない。人の集まりも、暴行も脅迫もない。王国基本法第九条は、剣を抜かないこと、争いを言葉と証拠で決めることを定めている。
- **当てはまらない理由**：目的も暴動もない。
- **保つための決め**：[利用規約](./terms.md)「ヌスクァマとは何か」、王国基本法第一条・第九条。

### 称号の詐称と標章の使用（軽犯罪法第1条第15号）

- **要件の要旨**：官公職・位階勲等・学位その他法令で定められた称号、または外国におけるこれらに準ずるものを、偽って名乗ること（詐称）。または、資格がないのに、法令で定められた制服・勲章・記章その他の標章や、それらに似せて作った物を用いること。
- **ヌスクァマの事実**：騎士王・騎士は、どの国の法令にも定められていない、創作の中の言葉である。ヌスクァマは国家ではないので、その称号は「外国におけるこれらに準ずるもの」にも当たらない。勲章・記章・制服などの物は作らず、国章は実在のどの記章にも似せていない。
- **当てはまらない理由**：名乗っているのは法令上の称号ではなく、物の標章も用いていない。さらに、法令上の称号と誤認させる使い方そのものを禁じている。
- **保つための決め**：[利用規約](./terms.md)「称号の扱い」（法令上の称号と誤認させる使い方の禁止、履歴書・名刺・公的な書類への記載の禁止）、王国基本法第八条、[名称と権利](./names.md)「国章」、[叙任の規程](./knighting.md)「良識の前提」。

### 公文書・旅券に関わる罪（刑法第155条、旅券法第23条）

- **要件の要旨**：行使の目的で、公務所や公務員の作るべき文書を偽造すること（刑法第155条）。他人名義の旅券を使うこと、偽造された旅券を行使の目的で譲り渡し、受け取り、所持することなど（旅券法第23条）。
- **ヌスクァマの事実**：旅券・身分証・証明書・任命書の類を作らない。叙任は、名簿にアカウント名を載せるだけで、書面を発行しない。
- **当てはまらない理由**：偽造の対象となる文書を作っていない。
- **保つための決め**：[利用規約](./terms.md)「ヌスクァマとは何か」（旅券・国籍を持たない）、[叙任の規程](./knighting.md)「叙任とは」（書面や物を発行しない）。
- **点検で足したこと（2026-11-12）**：刑法第155条の「公務所」と「公務員」は、同法第7条が定める日本の国や地方公共団体の職員と、その職務の場を指す。ヌスクァマの名で作られた書面は、この意味の公文書には当たらない。ただし、権利・義務・事実証明に関する文書を、行使の目的で、他人の名義で作れば、私文書偽造（刑法第159条）に近づく。騎士や第三者が「ヌスクァマの旅券」などを王や国の名義で作れば、この条に近づく。

### 詐欺（刑法第246条）

- **要件の要旨**：人を欺いて財物を交付させること。または、その方法で、財産上不法の利益を得ること。
- **ヌスクァマの事実**：お金も品物も受け取らない。称号を売らず、寄付を受けず、叙任は無償である。
- **当てはまらない理由**：財物や利益の移転がない。
- **保つための決め**：[利用規約](./terms.md)「費用」、王国基本法第六条、騎士王の十則の五。ヌスクァマの名で有料の称号を授けると称する者がいても関係がない、と利用規約に書いている。
- **点検で足したこと（2026-11-12）**：第三者がヌスクァマの名で称号を売っても、運営者がその行いを手伝わなければ、運営者は従犯（刑法第62条）にも当たらないと考える。利用規約に関係がないと書いたことは、この結論の理由ではない。知った時点で、関係がないことを表明する（「規程の外で、要件に近づく行い」）。

### 取引に関わる法令（特定商取引法第2条、景品表示法第5条、消費者契約法第2条・第8条・第10条）

- **要件の要旨**：販売業者や役務提供事業者が、訪問・通信・電話勧誘などで商品や役務を売ること（特定商取引法）。事業者が、自分の供給する商品や役務の取引について、著しく優良または有利と誤認させる表示をすること（景品表示法）。事業として契約の当事者となる者と消費者との契約で、事業者の損害賠償の責任の全部を免除する条項などは無効になる（消費者契約法）。
- **ヌスクァマの事実**：何も売らず、広告を出さず、営利の事業を営まない。
- **当てはまらない理由**：これらの法令が前提とする取引がない。消費者契約法については、万一適用される場合に備えて、[免責事項](./disclaimer.md)「責任」で、同法が適用されるときは免責の文を適用せず、軽過失による損害を含めて責任を負うと書いている。同法第8条第1項は責任の全部の免除を、第3項は軽過失に限ることを明らかにしない一部の免除を、無効とする。免責事項は、そのどちらにも当たらない。
- **保つための決め**：[利用規約](./terms.md)「費用」。
- **点検で足したこと（2026-11-12）**：景品表示法の「表示」は、事業者が自己の供給する商品や役務の取引について行う広告その他の表示である（景品表示法第2条第4項）。ヌスクァマには、その取引がない。
- **点検で足したこと（2026-11-12）**：消費者契約法の「事業者」は、法人その他の団体と、事業として、または事業のために契約の当事者となる個人である（消費者契約法第2条第2項）。条文は、事業に営利が要るとは書いていない。誰からでも叙任の願い出を受け、利用規約への同意を得ることを繰り返す運営が「事業として」に当たるかは、条文からは決まらない。運営者は、同法が適用されるものとして扱い、条ごとに確かめた。第8条第1項は、責任の全部の免除のほか、故意または重大な過失による責任の一部の免除も無効とする（第2号・第4号）。免責事項は、故意と重大な過失を免除の外に置き、同法が適用されるときは免責の文を適用しない。第8条の2（解除権を放棄させる条項）と第8条の3（後見開始などを理由とする解除権）に当たる条項はない。第9条（損害賠償の額の予定と違約金）については、利用規約が、違約金も法令が定める以上の賠償も求めないと書いている。第10条に照らす条項は、利用規約の合意管轄の定めと変更の定めである。合意管轄は専属的でなく、不利な変更は効力の前に示すので、運営者は、どちらも消費者の利益を一方的に害する条項に当たらないものとして扱う。利用規約は、法令が制限を認めない権利を制限しないと書いている。

### 定型約款（民法第548条の2・第548条の3・第548条の4）

- **要件の要旨**：定型取引を行うことの合意をした者は、定型約款を契約の内容とする旨の合意をしたときなどに、個別の条項にも合意をしたものとみなされる（第548条の2第1項）。相手方の利益を一方的に害すると認められる条項は、合意をしなかったものとみなされる（同条第2項）。求めがあれば、定型約款の内容を示す（第548条の3）。変更は、相手方の一般の利益に適合するとき、または契約の目的に反せず合理的なときにでき、効力の生じる時期と変更後の内容を、効力の前にインターネットなどで知らせる（第548条の4）。
- **ヌスクァマの事実**：叙任を願い出る人は、様式で、その日の版の規約に同意する。読むだけの人は同意しない。規程はすべて公開のリポジトリとサイトにある。不利な変更は、変える内容と効力の生じる日を、効力の前に利用規約に示す。
- **当てはまらない理由**：無償の叙任の願い出が「定型取引」に当たるかは、条文からは決まらない。当たる場合に備えて、同意は様式で得て、内容は公開し、変更は効力の前に示している。第548条の2第2項に照らす条項も、合意管轄の定めと変更の定めで、運営者は、消費者契約法第10条と同じ理由で、相手方の利益を一方的に害する条項に当たらないものとして扱う。
- **保つための決め**：[利用規約](./terms.md)「この規約が及ぶ人」「変更と終了」。

### 通貨と支払いの手段（資金決済法第3条）

- **要件の要旨**：金額や数量に応ずる対価を得て、証票や電子的な記録として発行され、代価の弁済や物品・役務の請求に使える前払式支払手段を発行すること。
- **ヌスクァマの事実**：通貨・点数・引換券・電子的な価値のどれも発行しない。
- **当てはまらない理由**：発行も取り扱いもない。
- **保つための決め**：[利用規約](./terms.md)「ヌスクァマとは何か」（通貨を持たない）。

### 商標と表示（商標法第25条、不正競争防止法第2条第1項第1号・第2号）

- **要件の要旨**：商標権者が専有する、指定商品や指定役務についての登録商標の使用を、権利なく行うこと（商標法）。需要者の間に広く知られた他人の商品等表示と同一または類似の表示を使い、混同を生じさせること。他人の著名な商品等表示と同一または類似のものを、自分の商品等表示として使うこと（不正競争防止法）。
- **ヌスクァマの事実**：営業をしない。名前は、ラテン語の一般語と古典の語に由来し、他人の商品や団体の表示を借りていない。国章は自作である。
- **当てはまらない理由**：営業上の使用がなく、他人の表示を使っていない。
- **保つための決め**：[名称と権利](./names.md)、[免責事項](./disclaimer.md)「実在のものとの関係」。
- **点検で足したこと（2026-11-12）**：商標法の「商標」は、業として商品を生産し譲渡する者や、業として役務を提供する者が、その商品や役務について使う標章である（商標法第2条第1項）。業として商品も役務も扱わないヌスクァマの名の使い方は、この定義の外にあると考える。不正競争防止法第2条第1項第1号・第2号の「営業」に営利が要るかは、条文からは決まらない。ヌスクァマは他人の商品等表示を使わないので、運営者は、営業に当たるかどうかにかかわらず、同号の要件に当たらないものとして扱う。

### 著作権（著作権法第21条・第23条）

- **要件の要旨**：著作者が専有する複製や公衆送信（送信可能化を含む）を、許諾なく行うこと。
- **ヌスクァマの事実**：文と国章は、運営者が Claude Code で書かせ、確かめたものである。他人の著作物は、この頁の「条文」と「原文」の欄に条約・法令・規約・説明の文を引くほかは、写していない。『ユートピア』や『荘子』は、名前の由来として挙げているだけで、本文を写していない。どちらも著作権の保護期間をとうに過ぎている。
- **当てはまらない理由**：頁は引用のほかに他人の著作物を載せず、リポジトリも、法令・条約と国の機関の文のほかは、引いた箇所と検査が拠る箇所だけを記す。引用は、次の項で著作権法第32条と照らす。
- **保つための決め**：[名称と権利](./names.md)、[削除・訂正・辞退の求め](./requests.md)（権利を侵す内容の削除の求め）。
- **点検で足したこと（2026-11-12）**：日本の法令は、著作権法第13条第1号により権利の目的とならない。外国の法令と条約が同号の「法令」に入るかは、条文からは決まらない。そこで、外国の文と、カリフォルニア州司法長官の説明と、Vercel の文書は、引用（著作権法第32条第1項）として扱う。同項の要件は、公表された著作物であること、公正な慣行に合致すること、引用の目的上正当な範囲内であることである。引く文は公開の頁の文で、この頁の説明の拠り所を示すために、要る一節だけを、本文と分けた欄に、出所の頁へのリンクとともに載せている（著作権法第48条第1項第1号の出所の明示）。そのため、要件に当たると考える。「公正な慣行」と「正当な範囲」の中身は、条文からは決まらない。運営者は、この形の引用を、二つに合うものとして扱う。言語モデルで書いた文が他人の文に似ていると分かったときは、その文を止めてから確かめ、直す。

### 個人情報（個人情報保護法第17条・第18条・第27条・第28条）

- **要件の要旨**：個人情報を扱う事業者は、利用の目的をできる限り特定し、その達成に必要な範囲を超えて扱わない。第三者に個人データを渡すとき、外国にある第三者に渡すときは、あらかじめ本人の同意を得るなどの決まりを守る。
- **ヌスクァマの事実**：扱うのは、GitHub のアカウント名・訂正へのリンク・本人が書いた説明だけで、本名・住所・連絡先は求めない。利用の目的、公開されること、米国の GitHub と Vercel で扱われることを示し、願い出の様式で本人が同意する。名簿からの辞退と削除に、いつでも無償で応じる。
- **当てはまらない理由**：法令が求める扱いを、規程と様式で満たしている。第32条の氏名と住所は、求めた人がプロフィールに公開した連絡先へ知らせ、連絡先のない人は一時的に公開すれば受け取れる。
- **項ごとの対応**：個人情報保護法第17条・第18条・第20条〜第23条・第25条〜第28条・第32条〜第38条・第40条と、同法施行令第10条、同法施行規則第7条・第8条・第10条・第17条の義務を、項ごとに規程の文と結んだ表を `verification/duties.json` に置いた。検査が、文の実在と、条文の見張りとの対応を確かめる。

### 名誉と信用（刑法第230条・第231条・第233条、民法第709条）

### 日本の外の法令

- ヌスクァマは日本から運営する、非営利の創作である。どの国でも、事業も取引もせず、金銭や有料の会員の勧誘もしない。
- 国によっては、自国の栄典や称号を偽って名乗ることを禁じている。ヌスクァマは、称号をこの国の外で使うことと、実在の称号や叙勲と誤認させる使い方を禁じている（王国基本法第八条、利用規約「称号の扱い」）。良識の前提（叙任の規程）も同じである。
- 例として、イタリアの 1951 年法律第 178 号第 8 条は、私人や団体が、名称を問わず騎士の称号などを授けることを禁じている。同条は、そうした称号を使う者も罰し、使う者の罰は授けたのが国外であっても及ぶ、としている。条文は、イタリアの公式の法令データベース [Normattiva](https://www.normattiva.it/uri-res/N2Ls?urn:nir:stato:legge:1951-03-03;178~art8) で、2026-11-08 に確かめた。こうした国に住む人の願い出は受けない（[叙任の規程](./knighting.md)「願い出ることができる人」）。
- **点検で足したこと（2026-11-12）**：同条が禁じるのは、私人や団体が授けることで、受ける人の住む国を要件にしていない。授けた者の罰（六月から二年）が国外で授けた外国人に及ぶかは、刑法典第 7 条・第 8 条・第 10 条からは決まらない。運営者は、確かめ終えるまで受付を止めている（叙任の規程「受付の停止」）。同第 6 条は、行いの一部か結果が国内で起きた罪を国内の罪とする。日本で、日本にいる人の名を名簿に記すことがこれに当たるかは、条文からは決まらない。運営者は、これも確かめ終えるまで受付を止めている。使う者の罰は罰金（ammenda）だけで、2016 年の委任立法第 8 号の除外の一覧に同法はなく、行政罰に替わったと読める。
- EU の一般データ保護規則（GDPR）は、EU の外の者にも、EU にいる人に役務を提供するときなどに及ぶことがある。及ぶ場合に備えて、扱う情報を本人が公開するものに限り、同意で受け、開示・訂正・削除の求めに無償で応じている（[個人情報の取り扱い](./privacy.md)）。GDPR 第 3 条第 2 項は、EU の外の管理者にも、EU にいる人に、支払いの有無を問わず物や役務を提供するときなどに及ぶ、としている。条文は [EUR-Lex](https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=CELEX:32016R0679) で、2026-11-08 に確かめた。
- **点検で足したこと（2026-11-12）**：GDPR が第 3 条第 2 項で及ぶときは、EU の外の管理者は、EU の中に代理人を書面で指名する（GDPR 第27条）。ただし、取り扱いが時々のもので、特別な種類のデータを大規模に扱わず、人の権利と自由に危険を生じさせそうにないときは、指名の義務がない（同条の第 2 項 (a)）。ヌスクァマは EU の人に向けて役務を差し出しておらず、2026-11-22 からは日本の外にいる人の願い出を受けない。及ぶとしても、名簿の取り扱いは第 2 項 (a) に当たると考え、代理人は指名していない。2026-11-12 に Claude が決めました。名簿が扱うのはアカウント名と訂正の要約だけで、特別な種類のデータを求めていないためです。
- 米国カリフォルニア州の消費者プライバシー法（CCPA）は、営利の事業者を対象とする。ヌスクァマは営利の事業をしないので、当たらないと考える。カリフォルニア州司法長官の [CCPA の頁](https://oag.ca.gov/privacy/ccpa)で、営利の事業者が対象で、非営利の団体には一般に及ばないことを、2026-11-08 に確かめた。州法の条は、Internet Archive の写しで確かめた（点検の記録）。
- 2026-11-22 から、願い出は日本に住み、願い出のときに日本にいる人に限る。日本の外の法令は国ごとに確かめきれないので、及ぶおそれのある国に住む人を、はじめから受けない。外国の法令には、そこにいる人に及ぶものがあるので、旅行・出張・留学などで日本の外にいるあいだの願い出も受けない（[叙任の規程](./knighting.md)「願い出ることができる人」）。
- 2026-11-22 から、イタリアの国籍を持つ人（重国籍を含む）の願い出も受けない。理由は、イタリアの国民が日本のミクロネーションの騎士になるのは常識に照らして場違いであることと、上の条の使う者の罰が、国外で授けた称号を使ったイタリアの国民に及ぶことである。
- 2026-11-22 から、外国の称号を受けることを縛る国の国籍を持つ人の願い出も受けない（[叙任の規程](./knighting.md)「外国の称号を縛る国」）。

## 審査の方法と、前提が崩れる道

この頁の結論は、次の五つの方法で確かめました。

1. **要件の論理式**：罪や義務は、要件がすべてそろったときにだけ成り立つ。要件を A₁ ∧ A₂ ∧ … ∧ Aₙ と置けば、事実が一つの Aᵢ を否定するだけで全体が偽になる。法令ごとに、どの要件をどの文が否定しているかを `verification/legal-matrix.json` に並べ、検査がその文の実在を確かめる。
2. **網羅**：行う者（運営者・願い出る人・騎士・読む人・第三者）と、行い（公開する・受け付ける・名簿に載せる・称号を使う・情報を保つ・国外に及ぶ）の組を、`verification/legal-matrix.json` にすべて並べた。どの組も、この頁のどれかの項が扱うか、起こらない組である。
3. **無矛盾**：同じ事柄を、頁ごとに違って書いていないかを突き合わせた。「この国の中」の範囲が頁ごとに違っていたので、利用規約の一か所で定め、ほかの頁はそこを指すように改めた（[王の正誤表](../ERRATA.md) 6）。
4. **故障の木**：前提の事実が崩れる道を並べ、起こりやすさと重さを 1 から 3 で見積もり、その積で順を付けた。数は運営者の見積もりで、順を付けるためだけのもの。
5. **壊して確かめる**：固めた文を一つずつ書き換え、検査が落ちることを見た。

この方法は、並べた要件の範囲で働きます。
2026-11-12 の点検で、並べていなかった法令と、解釈の分かれる要件が見つかりました。どちらも、上の各節の「点検で足したこと」と、初めに挙げた点検の記録にあります。

## 管轄の合意の効き方

利用規約は、示談を優先したうえで、第一審の合意管轄裁判所を定めています。この定めがどこまで効くかを、ここに書きます。

- **法令の要旨**：当事者は、第一審に限り、合意で管轄裁判所を定めることができる。合意は、一定の法律関係に基づく訴えについて、書面か電磁的記録でしなければ効力を生じない（民事訴訟法第11条）。将来の消費者契約の紛争について国の裁判所を定める合意は、消費者の住所がある国の裁判所に訴えられるときなど、限られた場合にだけ効力を持つ（民事訴訟法第3条の7第5項）。
- **ヌスクァマの事実**：叙任を願い出る人は、様式で利用規約への同意に印を付ける。その印は issue に残る。サイトやリポジトリを読むだけの人は、何にも印を付けない。
- **効き方**：合意は、様式で同意した人との間で、規約と、その人自身の願い出・名簿への記載・辞退に基づく訴えにだけ置き、専属的ではない。同意の記録は電磁的記録として残る。読むだけの人とは書面の合意がなく、ほかの紛争とあわせて、法令の定める裁判所が管轄する。運営者から訴えるときは、宇都宮の裁判所か相手の普通裁判籍の地に限る。利用規約は、消費者や日本国外の人が、法令によって別の裁判所で訴える権利を奪わないと書いている。
- **点検で足したこと（2026-11-12）**：様式の同意の印は、規約の文を写したものではなく、規程の所在を指す。どの版に同意したかは、願い出の日とリポジトリの履歴で確かめる。issue を消す求めに応じれば、同意の記録もなくなる。合意で定めた裁判所でも、当事者の衡平を図るため必要があれば、ほかの管轄裁判所へ移されうる（民事訴訟法第17条）。消費者からの訴えは、消費者の住所が日本にあれば、日本の裁判所に起こせる（民事訴訟法第3条の4第1項）。消費者契約法が適用されるときの合意管轄の定めの扱いは、「取引に関わる法令」の節に書いた。
- **保つための決め**：[利用規約](./terms.md)「準拠法と紛争」、叙任の願い出の様式の誓い。

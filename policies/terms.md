# 利用規約

最終更新：2026-11-13。

## この規約が及ぶ人

この規約は、ヌスクァマのサイトとリポジトリを読む人、叙任を願い出る人、騎士の名簿に名がある人のすべてに及びます。
叙任を願い出る人は、願い出の様式で、その日の版のこの規約に同意します。
サイトやリポジトリを読むことを、何かへの同意とはみなしません。読む人にとって、この規約はヌスクァマの仕組みを示すもので、双方が負うものは法令が定めます。
裁判所の合意は、叙任の願い出の様式で同意した人との間にだけ置きます（「準拠法と紛争」）。
[免責事項](./disclaimer.md)・[個人情報の取り扱い](./privacy.md)・[叙任の規程](./knighting.md)・[削除・訂正・辞退の求め](./requests.md)・[名称と権利](./names.md)も、この規約の一部です。
ヌスクァマが法令に触れないと運営者が考える理由は、[適法性の説明](./legality.md)に法令ごとに書いてあります。適法性の説明は、規約の一部ではなく、運営者の理解の説明です。

## ヌスクァマとは何か

ヌスクァマは、運営者が遊びとして書いている創作です。
国家ではありません。領土・国民・政府・通貨・旅券・国籍を持たず、主権も領有も主張しません。
国際法上の国家ではなく、国家としての承認を求めず、どの国とも外交の関係を結びません。
実在の国家・王室・騎士団・叙勲・栄典・称号のいずれとも関係がなく、それらを名乗るものでも、それらに代わるものでもありません。
通貨・点数・引換券・電子的な価値・旅券・身分証・証明書のどれも発行しません。
「騎士王ネモ一世」は、運営者が創作の中で演じる役の名です。

## 悪意がないことと、法令を守ること

ヌスクァマに悪意はありません。人をだますことも、誰かを害することも、目的にしていません。
運営者は、日本の法令と、使っているサービスの規約を守って運営します。
法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します。
適法かどうか迷う事柄は、行わないほうを選びます。

## 称号の扱い

ヌスクァマの称号（騎士王・騎士・正誤表騎士団の団員）は、創作の中の言葉です。
どの国の法令に定められた称号でもなく、法的な効力も、身分も、特典もありません。
叙任は、どの国の勲章・栄典・騎士の位（騎士団の位を含みます）を授けるものでもなく、遊びに加わった人のアカウント名を名簿に記すことです。騎士の呼び名は、その記載に添える創作の中の役の名です。
称号は、この国の中でだけ使います。
この国の中とは、このリポジトリとサイト、そして運営者がこの国を紹介するために自ら書いた記事や投稿（[README](../README.md)「ほかの場所」に挙げたもの）を指します。
ヌスクァマは、勲章・記章・制服・証書などの物を作らず、配りません。
官公職・位階勲等・学位・その他法令により定められた称号と誤認されるように使うことは、してはいけません。
履歴書・論文・名刺・公的な書類・商取引・広告に、ヌスクァマの称号を書いてはいけません。
2026-11-22 から、騎士の呼び名は、ヌスクァマに関わることにだけ使います。
2026-11-22 から、騎士の呼び名を、どの国の貴族の称号・栄典・勲章・位階・尊称としても示さず、公的な場・商取引・法的な場で使いません。
2026-11-22 から、これに反したときは、運営者は名簿から名を外します（[叙任の規程](./knighting.md)「騎士の呼び名の使い方」）。

## 費用

ヌスクァマは、誰からも料金を取りません。
称号を売らず、寄付を受けず、広告を出さず、何も販売しません。
叙任の願い出にも、名簿への記載にも、費用はかかりません。
ヌスクァマの称号を有料で授けると称する者がいても、ヌスクァマとは関係がありません。

## してはいけないこと

- 他人の誤りや、自分のものでない訂正で叙任を願い出ること。
- 他人の個人情報（本名・住所・連絡先・写真など）を issue に書くこと。
- 他人を中傷し、脅し、または嫌がらせをすること。
- ヌスクァマの称号や国章を、実在の称号・叙勲・団体の記章であるかのように使うこと。
- ヌスクァマの名で、金銭や物品を集めること。
- サイトや様式を壊そうとすること。
- 願い出の様式で、事実でないことに印を付けること。例として、年齢、住んでいる国、国籍、訂正が自分の誤りであることがあります。

運営者は、これらに当たる願い出を断り、issue を閉じ、名簿から名を外すことがあります。
印が事実でないと分かったときは、運営者は、知った時点で名簿から名を外します。2026-11-22 からは、同じ GitHub アカウントからのその後の願い出を断ることもあります。
運営者は、印を信頼して受け、確かめません。事実でない印で叙任された人がいても、ヌスクァマが願い出を受けないとする国に住む人や、受けないとする国籍を持つ人を受けたことにはなりません。
印は、本人の求めで削除するまで、公開の issue に残るので、何にいつ印を付けたかを示せます。
願い出た人に、違約金や、法令が定める以上の損害の賠償を求めることはありません。

## 保証しないこと

サイトとリポジトリは、現状のまま提供します。
いつでも読めることも、内容に誤りがないことも保証しません。
詳しくは[免責事項](./disclaimer.md)にあります。

## 変更と終了

この規約とほかの規程は、変わることがあります。
各頁の日付が最後の変更を示し、過去の版は公開のリポジトリに残ります。
頁の日付と、年表・官報・正誤表・名簿の日付は、日本時間の日付です。
文を取り寄せた日は、取り寄せの記録に残った協定世界時の日付です。
建国の日の 2026-11-07 も、協定世界時の日付です。
読む人や騎士に不利になる変更は、変える内容と効力の生じる日を、効力の生じる前にこの頁で示します。
予告：2026-11-22 から、叙任を願い出ることができるのは、日本に住んでいて、願い出のときに日本にいる人に限ります。イタリアの国籍を持つ人と、外国の称号を縛る国の国籍を持つ人を除き、国籍は問いません（[叙任の規程](./knighting.md)「願い出ることができる人」）。
予告：2026-11-22 から、イタリアの国籍を持つ人は、日本に住んでいても、ほかの国籍と重ねて持っていても、叙任を願い出ることができません（[叙任の規程](./knighting.md)「願い出ることができる人」）。
予告：2026-11-22 から、外国の称号を受けることを縛る国の国籍を持つ人は、日本に住んでいても、ほかの国籍と重ねて持っていても、叙任を願い出ることができません（[叙任の規程](./knighting.md)「外国の称号を縛る国」）。
予告：2026-11-22 から、叙任の規程「外国の称号を縛る国」の表に、イエメン・オーストリア・ギリシャを足します。この三つの国の国籍を持つ人も、日本に住んでいても、ほかの国籍と重ねて持っていても、叙任を願い出ることができません（2026-11-13 に示しました）。
予告：2026-11-22 から、騎士の呼び名は、ヌスクァマに関わることにだけ使い、どの国の貴族の称号・栄典・勲章・位階・尊称としても示さず、公的な場・商取引・法的な場で使いません。反したときは名簿から名を外します（「称号の扱い」）。
予告：2026-11-22 から、叙任は、願い出る人が称号を遊びとして扱う良識ある人であることを前提とし、様式でこの前提に印のない願い出は受けません（[叙任の規程](./knighting.md)「良識の前提」）。
予告：2026-11-22 から、事実でない印を付けた GitHub アカウントからのその後の願い出を断ることがあります（「してはいけないこと」）。
2026-11-12 から、叙任の願い出を受け付けていません（[叙任の規程](./knighting.md)「受付の停止」）。「悪意がないことと、法令を守ること」の、法令に触れるおそれが分かった部分を止める定めによります。
予告：2026-11-22 0 時（日本時間）からも、叙任の願い出の受付を止めたままにし、受付に戻る日は決めていません。授けることに関わるイタリアの法令の一点が、条文からは決まらないためです。受付に戻すときは、戻る日を、叙任の規程とこの頁で、その日より前に示します（2026-11-13 に示しました）。
どの変更によっても、料金は生じません。
ヌスクァマは、予告なく終わることがあります。終わる場合も、騎士の名簿は、本人から辞退の求めがない限り、リポジトリに残します。

## 準拠法と紛争

この規約は日本法に準拠します。
この規約のどの定めも、法令が制限を認めない権利を制限しません。
紛争は、示談による解決を優先します。
運営者は、訴えを起こす前に、まず相手方と話し合います。
話し合いは、issue で行います。相手方が自分の GitHub のプロフィールに連絡先を公開しているときは、その連絡先で行うこともできます（[削除・訂正・辞退の求め](./requests.md)「公開できない求め」）。
相手方から示談の申し出があれば、運営者は誠実に応じます。
示談で解決しない紛争のうち、この規約に基づく訴えと、その人自身の叙任の願い出・名簿への記載・辞退に基づく訴えは、叙任の願い出の様式でこの規約に同意した人との間では、訴額に応じて、宇都宮地方裁判所または宇都宮簡易裁判所を、第一審の合意管轄裁判所とします。
この合意は専属的なものではありません。
それ以外の紛争と、様式で同意していない人との間の紛争は、法令の定める裁判所が管轄します。
運営者がこの規約の及ぶ人に訴えを起こすときは、宇都宮地方裁判所・宇都宮簡易裁判所か、訴える相手の普通裁判籍の所在地を管轄する裁判所にだけ起こします。
相手方が宇都宮地方裁判所または宇都宮簡易裁判所に訴えを起こしたときは、運営者は、どの紛争でも管轄を争いません。
これは、消費者や日本国外の人が、法令によって別の裁判所で訴える権利を奪うものではありません。

## GitHub と Vercel の規約

ヌスクァマは、米国の二つのサービスの上で動いています。願い出と求めは GitHub の issue で受け、サイトは Vercel が配信します。

- GitHub が受け入れる利用者は、13 歳以上の人です（GitHub の利用規約 B.3）。叙任を願い出ることができるのは、それより上の 16 歳以上の人です。

# デザインに関する法的な扱い

最終更新：2026-11-23。

## この頁について

この頁は、サイトの見た目の部品について、誰が作ったか、どこから来たか、権利と許諾がどうなっているか、どの法令の条にどう関わるかを記します。
部品は、書体、国章・国旗・ファビコン・アイコン・共有したときの画像、版図の地図と頁の中の図、配色と配置です。
運営者自身の理解を書いたものです。法的な助言ではなく、弁護士の確認も受けていません。
条文は、このリポジトリの [verification/statutes-texts.json](../verification/statutes-texts.json)（コミット 85dd680、e-Gov 法令 API から 2026-11-22 に取り寄せ）の写しのとおりに引きます。写しは、見張りが取り寄せて記したものです。
条を挙げる文の中で「」に入れた語句は、写しから一字一句そのまま切り出したものです。
名と国旗・国章の商標の扱い、調べた記録、権利者から知らせが来たときの手順は、[名称と権利](./names.md)にあります。この頁は、それを繰り返さず、そちらへつなぎます。
2026-11-22 に利用者が求め、Claude が書きました。

### 書体

サイトは、書体のファイルを配りません。
スタイルに、書体のファイルを読み込む規則（font-face）はなく、書体を外から読み込むこともしません。
スタイルで書体を決める所は **2** か所です。どちらも、閲覧者の端末にある書体の名を並べて名指すだけです。
端末に名指したどの書体もなければ、総称の書体（`serif`・`ui-monospace`・`monospace`）に任せます。
名指した書体は、閲覧者の端末にあるもので、それぞれの権利者のものです。
国章・国旗・版図の地図は、書体を使いません（[国のしるし](../SYMBOLS.md)の「国の書体」）。

### 頁の中の図

頁の中の図は、`build.js` が、王の正誤表・年ごとの版図・しるしの作図の頁を作るときに描きます。
どの図も、国の色の長方形と多角形だけでできていて、文字を描きません。
どの図にも題（title）を付けます。

### 配色と配置

配色と配置は、`build.js` のスタイル一つで決めます。
スタイルは頁ごとの `<style>` に入れ、外のスタイルシートを読みません。
どの頁も、ほかのサーバーから何も読み込みません（CSP の `default-src 'none'`）。

頁の奥行きも、同じスタイルの中で、高さの段として決めます。
高さは **4** 段です。奥から順に、地（頁の背景）、面（断りの枠・入口の札・表）、浮いた面（広い画面で本文を載せる紙・トップの断りの枠・国旗と地図）、最前面（頁の上の欄と、ポインタを重ねた札）です。
影は `--e1`・`--e2`・`--e3` の **3** 段です。
地は影を持たず、面は `--e1`、浮いた面は `--e2`、最前面は `--e3` を使います。
光は左上の一方向から当て、どの影も右下に落とします。
暗い配色では影を短くし、面の明るさの差と、上と左の縁の明かりで高さを示します。
国章・国旗・版図の地図は、形も色も変えません。額の縁と影だけで手前に出します。
入口の札と、トップの国旗と地図は、ポインタを重ねたときとフォーカスしたときに影が深くなり、**2** px 浮きます。
動き（animation・transition）は使わず、位置が一度に変わるだけです。端末が動きを減らす設定のときは位置を変えず、影だけを深くします。
余白は **7** 段、角の丸みは **3** 段の変数から取ります。
幅が **840** px 以上の画面では、本文を紙の面に載せ、一行を全角でおよそ **37** 字にします。
印刷では、影とぼかしと面の色の移り変わりを外し、平らに戻します。
奥行きは、2026-11-23 に利用者が求め、Claude が決めました。

## 著作権

著作権法第2条第1項第1号は、著作物を「思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するもの」と定めます。
同法第10条第1項第4号は、著作物の例として「絵画、版画、彫刻その他の美術の著作物」を挙げます。
国章・国旗・アイコン・版図の地図と頁の中の図が美術の著作物に当たるかどうかは、条文だけからは決まりません。
どれも、長方形と多角形を、[国のしるし](../SYMBOLS.md)の作図に書いた寸法で並べた図です。
言語モデルを使って作ったものに著作権がどこまで及ぶかが定まっていないことは、[名称と権利](./names.md)の「ライセンス」にあります。

### 許諾

リポジトリの [LICENSE](../LICENSE) は CC BY 4.0 です。
部品の一覧の画像、頁の中の図、スタイルは、この許諾で公開しています。
CC BY 4.0 は、権利が及ぶ範囲で許すものです。
許諾は変えません。

### 著作者人格権

著作権法第19条は、著作者が「その実名若しくは変名を著作者名として表示し、又は著作者名を表示しないこととする権利」を持つと定めます。
同法第20条は、著作者が「その著作物及びその題号の同一性を保持する権利」を持つと定めます。
CC BY 4.0 の Section 2(b)(1) は、同一性保持権などの人格権を許諾の外に置きます。そのうえで、許諾した使い方に要る限りで、許諾者がその権利を放棄するか、行使しないと定めます。
どの頁の下の欄も、運営者と、文と国章が CC BY 4.0 であることと、Claude Code で書いたことを示します。

<!-- 条文 著作権法 第19条、著作権法 第20条 -->

### 他人の素材

サイトは、他人の画像・書体・アイコン・図を使っていません。
そのため、他人の素材の許諾の文と条件は、この頁にありません。

## 商標・意匠・不正競争

### 商標

運営者は、ヌスクァマの名としるしの商標の登録を、日本でもほかの国でも出願していません（[名称と権利](./names.md)の「名称と商標」）。
商標法第25条は、商標権者が「指定商品又は指定役務について登録商標の使用をする権利を専有する」と定めます。
ヌスクァマは、この条による権利を持ちません。

<!-- 条文 商標法 第25条 -->

### 意匠

意匠法第2条第1項は、意匠を、物品の形状等、建築物の形状等、または画像であって「視覚を通じて美感を起こさせるもの」と定めます。
同項の画像は、「機器の操作の用に供されるもの又は機器がその機能を発揮した結果として表示されるもの」に限られます。
同法第23条は、意匠権者が「業として登録意匠及びこれに類似する意匠の実施をする権利を専有する」と定めます。
国章・国旗・アイコン・頁の形について、意匠登録を出願した記録は、このリポジトリにありません。
他人の登録意匠と突き合わせた記録もありません。確かめていません。
ヌスクァマは、何も売らず、物を作らず、配りません（[利用規約](./terms.md)）。

<!-- 条文 意匠法 第2条、意匠法 第23条 -->

### 表示と形態

不正競争防止法第2条第1項第1号・第2号の商品等表示の扱いは、[適法性の説明](./legality.md)の「商標と表示（商標法第25条、不正競争防止法第2条第1項第1号・第2号）」にあります。
同項第3号は、「他人の商品の形態（当該商品の機能を確保するために不可欠な形態を除く。）を模倣した商品」を譲渡し、または電気通信回線を通じて提供することなどの行為を挙げます。
ヌスクァマは、商品を作らず、売らず、配りません。
国章・国旗・アイコンを、他人の商品の形態と突き合わせた記録はありません。確かめていません。
国旗と国章が実在の国旗や紋章を写していないことと、その確かめ方は、[名称と権利](./names.md)の「国旗と国章」にあります。

## 見やすさ

この頁は、障害を理由とする差別の解消の推進に関する法律を、障害者差別解消法と呼びます。
障害者差別解消法第2条第7号は、事業者を「商業その他の事業を行う者（国、独立行政法人等、地方公共団体及び地方独立行政法人を除く。）」と定めます。
同法第8条は、事業者が、不当な差別的取扱いによって障害者の権利利益を侵害してはならないことと、社会的障壁の除去について必要かつ合理的な配慮をすることを定めます。
運営者がこの法律の事業者に当たるかどうかは、条文からは決まりません。この頁は、それを決めません。

<!-- 条文 障害者差別解消法 第2条、障害者差別解消法 第8条 -->

### サイトがしていること

次の事柄は、どれも [verification/check.js](../verification/check.js) か、CI の別の job が確かめています。

- 配色：明るい配色と暗い配色を、端末の設定で切り替えます。どちらの配色でも、文字と背景の組は 4.5:1 以上、フォーカスの枠と背景の組は 3:1 以上です。色はすべて二つの配色の変数から取ります。
- 色だけに頼らないこと：版図の区画は金一色で、誤りの分類は形で分けます。分類ごとに形が違います。
- 動き：スタイルに、動き（animation・transition）がありません。札が浮くときも、位置が一度に変わるだけです。動きを減らす設定では、位置を変えません。
- 代替テキスト：頁の上の国章は飾りとして空にし、中身の画像には何の画像かと「（創作）」を書きます。頁の中の図には題を付けます。
- 言語と見出し：どの頁も言語を示し、h1 を一つ持ち、見出しの段を飛ばしません。
- キーボード：どの頁も、先頭に「本文へ」のリンクを置きます。スタイルは、フォーカスした所に枠を描きます。
- 拡大：拡大を止めません。360 px と、200% に当たる 640 px の幅で、横にはみ出さないことを、CI の別の job がブラウザで描いて確かめます。

読み上げの道具で聞くこと、キーボードだけで通して操作すること、色覚の型ごとの見え方は、確かめていません。

## 人と団体

SVG の画像と頁の中の図は、どれも長方形と多角形だけでできています。
PNG と ICO の画像は、国章を描いたものです。
実在の人の肖像や写真は、どの画像にもありません。
国旗と国章が実在の国家・王室・騎士団・勲章・大学・企業の紋章や記章を写していないことは、[名称と権利](./names.md)の「国章」と「国旗と国章」にあります。
ほかの者のロゴを配らないことは、同じ頁の「ほかの者の名」にあります。

## 変わったとき

部品を足したり、変えたり、外したりするときは、同じ PR で、この頁と検査を直します。
検査は、この頁の部品の一覧と、配る画像が食い違えば落ちます。
変えたことは、[年表](../README.md)と官報に記します。

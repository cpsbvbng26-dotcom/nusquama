国際法上の国家ではなく、国家としての承認を求めず、どの国の領土も主張しません。
建国の宣言・王国基本法・十則・国章は、創作の中の文書です。
ヌスクァマに悪意はありません。人をだますことも、誰かを害することも、目的にしていません。
悪意がないことと法令を守ることは、[利用規約](./terms.md)「悪意がないことと、法令を守ること」で約束しています。

## 称号に効力がないこと

騎士王・騎士・正誤表騎士団の団員といった呼び名は、創作の中の言葉です。
どの国の法令にも定められておらず、法的な効力・身分・特典・名誉は伴いません。
叙任は、現実の栄誉の授与ではありません。
名簿に名があることは、その人が何らかの資格や地位を持つことを示しません。

## 正確さと可用性

サイトとリポジトリは、現状のまま提供します。
誤りがないこと、いつでも読めること、将来も続くことを保証しません。
サイトは Vercel が配信し、リポジトリと issue は GitHub が保管しています。これらのサービスが止まれば、ヌスクァマも読めなくなります。
GitHub と Vercel は、それぞれ自らの規約で、サービスを「現状のまま」保証なしに提供し、責任を限っています。ヌスクァマは、二つのサービスについて、それぞれが約束する以上のことを約束できません。
サイトは Vercel の無料の Hobby プランで配信しており、Vercel はこのプランの配信を、予告の有無を問わず止めたり削除したりできます。二つの規約の定めは、[利用規約](./terms.md)の「GitHub と Vercel の規約」にあります。
GitHub の規約は、GitHub が GitHub Actions の利用を制限することを認めています。Actions が止まることもあります。
そのあいだは、叙任の願い出の自動の確認も、受付を止めているあいだに願い出を閉じることも、週ごとの見張りも、年一回の総点検の issue も、ひとりでには動きません。運営者が手で行い、すぐには行われません。
記載を判断の前に外すことは、初めから運営者が手で行っており、GitHub Actions には頼りません。

# 免責事項

最終更新：2026-11-08。

この頁は、ヌスクァマが約束しないことと、ヌスクァマが何でないかを、一か所にまとめたものです。
拘束力を持つのは[利用規約](./terms.md)です。この頁と食い違う場合は、利用規約が適用されます。

## 創作であること

ヌスクァマは、遊びとして書かれた創作です。
国家・政府・自治体・王室・貴族の家・騎士団・宗教団体・叙勲や栄典の制度のいずれでもありません。
国際法上の国家ではなく、国家としての承認を求めず、どの国の領土も主張しません。
建国の宣言・王国基本法・十則・国章は、創作の中の文書です。

## 称号に効力がないこと

騎士王・騎士・正誤表騎士団の団員といった呼び名は、創作の中の言葉です。
どの国の法令にも定められておらず、法的な効力・身分・特典・名誉は伴いません。
叙任は、現実の栄誉の授与ではありません。
名簿に名があることは、その人が何らかの資格や地位を持つことを示しません。

## 実在のものとの関係

ヌスクァマは、次のどれとも関係がありません。

- 実在の国家・王室・政府・自治体
- 実在の騎士団・騎士修道会・勲章・叙勲や栄典の制度（日本の栄典、英国の叙勲などを含む）
- いわゆるミクロネーション（自称国家）のうち、ヌスクァマ以外のすべて
- アーサー王伝説を題材とする小説・映画・ゲーム・アニメなどの作品と、その権利者
- トマス・モア『ユートピア』や、ジュール・ヴェルヌ『海底二万里』を出版・翻案する者

「ヌスクァマ」「ネモ」「無何有」の語の由来は[名称と権利](./names.md)に書いてあります。どれも、特定の作品や団体との結び付きを示すものではありません。

## 叙任の願い出について

叙任の願い出は、公開の issue で受けます。
願い出に書かれた訂正の内容が正しいかどうかを、運営者は保証しません。
騎士の名簿に名があることは、その人の訂正や研究や人柄を、運営者が推薦することを意味しません。

## 正確さと可用性

サイトとリポジトリは、現状のまま提供します。
誤りがないこと、いつでも読めること、将来も続くことを保証しません。
サイトは Vercel が配信し、リポジトリと issue は GitHub が保管しています。これらのサービスが止まれば、ヌスクァマも読めなくなります。

## 助言ではないこと

ヌスクァマの文書は、法的・専門的な助言ではありません。
規程の中で法令に触れている箇所も、運営者の理解を書いたもので、法的な判断ではありません。
法令ごとの整理は[適法性の説明](./legality.md)にあります。弁護士の確認は受けていません。

## 責任

ヌスクァマは無償の創作であり、運営者は、サイトやリポジトリの利用から生じた損害について、法令が許す範囲で責任を負いません。
日本の消費者契約法が適用される場合、運営者は、自らの過失で生じさせた損害について、同法の定めるとおり責任を負います。
故意または重大な過失による責任や、法令が免除や制限を認めない責任を、免除したり制限したりするものではありません。

# 削除・訂正・辞退の求め

最終更新：2026-11-08。

## 求めることができるもの

- 騎士の名簿からの辞退（名を外す）。
- 名簿や issue に書かれた、自分についての記載の訂正・削除。
- 自分についての保有個人データの利用目的の通知・開示・訂正・追加・削除・利用停止・消去・第三者への提供の停止。
- 自分の個人情報が、自分の同意なく書かれている場合の削除。
- 自分の権利（著作権・商標・肖像など）を侵す内容の削除。
- ヌスクァマが実在の何かと誤認されるおそれがあるときの、表現の修正。

費用はかかりません。

## 求め方

[削除・訂正・辞退の求め](https://github.com/cpsbvbng26-dotcom/nusquama/issues/new?template=request.yml)の様式で issue を開き、どの記載について、何を求めるかを書きます。
様式を使わない issue は開けないようにしてあります。
窓口は GitHub だけです。ヌスクァマは、GitHub の外に連絡先を持ちません。GitHub の無料のアカウントで足ります。
求めは、代理人が出すこともできます。そのときは、本人の GitHub アカウントから、代理を頼んだことを issue に一言書いてもらいます。
問題の個人情報そのものを、issue に書き写さないでください。どこにあるかだけを書きます。

## 公開できない求め

公開の場で書けない事情がある場合は、様式の種類で「非公開の連絡を求める」を選び、ほかは空のまま出してください。
運営者から、非公開で連絡する方法を返します。
サイトやリポジトリの安全の問題も、同じ手順で知らせます（[安全の問題の知らせ方](../SECURITY.md)）。

## 求めを受けた後

運営者は、それぞれの求めに 7 日以内に答えることを目指します。
個人情報の露出のように害が大きいものは、判断の前に、その記載をただちに外します。
名簿からの辞退は、理由を問わず応じます。
開示・訂正・利用停止などの求めには、遅滞なく応じます。開示は、求められた方法で行います。電磁的記録で求められたときは、電磁的記録で渡します。
求めに応じたときは、何をしたかを遅滞なく知らせます。求められたデータがないときや、求められた方法で渡せないときも、その旨を遅滞なく知らせます。
求めに応じない場合は、その理由を答えます。

## 外せないもの

リポジトリの過去の版は、履歴を書き換えない限り残ります。ほかの者がすでに写したものは、運営者の手の外にあります。
Vercel に残る過去の配信は、求めがあれば、その記載を含むものを Vercel から消します。
リポジトリの履歴から消す必要がある場合は、運営者が GitHub にその削除を求めます。

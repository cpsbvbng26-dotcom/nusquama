# 叙任の規程

最終更新：2026-11-13。

## 叙任とは

叙任は、創作の中で、騎士の呼び名を贈ることです。
法的な効力・身分・特典・名誉は伴いません。
叙任は、どの国の勲章・栄典・騎士の位を授けるものでもありません。
叙任は無償です。金銭・物品・役務と引き換えにしません（王国基本法第六条）。
叙任では、任命書・証書・記章などの書面や物を発行しません。名簿にアカウント名を載せるだけです。

## 基本法第六条との関係

王国基本法第六条は、叙任の条件を、自分の誤りを一つ公に訂正したことの一つとしています。
この規程の条件は、第六条の条件に加わります。
この規程が条件を足すところは、この規程に従います。
足した条件は、年齢、住む国、願い出のときにいる国、国籍、良識の前提と、受付の停止です。
2026-11-29 からは、「法令に適合しない国と地域」の定めも、足した条件に加わります。
第六条の条件を満たしても、この規程の条件を満たさない人は、叙任しません。
2026-11-13 に Claude が決めました。基本法の条を改めずに、第六条の条件だけで叙任されると読まれないためです。

## 願い出ることができる人

自分の誤りを一つ、公に訂正したことがある人です。
訂正は、論文の正誤表、ブログや記事の追記、コードの修正、発言の取り消しなど、公開されていて誰でも確かめられるものに限ります。
16 歳未満の人は願い出ることができません。
住んでいる国の法令が、私人の授ける騎士の称号を受けることや使うことを禁じている人も、願い出ることができません。例として、イタリアの 1951 年法律第 178 号第 8 条は、私人や団体が、名称を問わず騎士の称号などを授けることを禁じています。
2026-11-22 から、願い出ることができるのは、日本に住んでいて、願い出のときに日本にいる人に限ります。イタリアの国籍を持つ人と、「外国の称号を縛る国」の国籍を持つ人を除き、国籍は問いません。
2026-11-22 から、日本の外に住む人は、国籍を問わず願い出ることができません。日本の外の法令を、国ごとに確かめきれないためです。
2026-11-22 から、日本に住んでいても、旅行・出張・留学などで日本の外にいるあいだは、願い出ることができません。外国の法令には、そこに住む人だけでなく、そこにいる人に及ぶものがあるためです。
2026-11-22 から、イタリアの国籍を持つ人は、日本に住んでいても、ほかの国籍と重ねて持っていても、願い出ることができません。理由は二つです。
一つめに、イタリアの国民が日本のミクロネーションの騎士になることは、常識に照らして、そもそも場違いです。
二つめに、イタリアの 1951 年法律第 178 号第 8 条は、称号を使う者も罰し、使う者の罰は授けたのが国外であっても及ぶとしています。同条の終わりの段落が国外として挙げるのは、授けた場所（「quando il conferimento delle onorificenze, decorazioni o distinzioni sia avvenuto all'estero」）だけです。称号を使う場所は書いていません。イタリアの外で称号を使うイタリアの国民にこの罰が及ぶかは、取り寄せた条文からは決まりません。
イタリアの国籍を持つ人を除くのは、運営者の決めです。この決めは願い出る人を除くだけで、同条がどこまで及ぶかを述べるものではありません。
同条の授けた者の罰が運営者に及ぶかは、取り寄せた条文からは決まりません。運営者は、そのために受付を止めています（「受付の停止」、[適法性の説明](./legality.md)「日本の外の法令」）。
旅行などで日本に短く滞在しているだけの人は、日本に住んでいる人に当たりません。
2026-11-29 から、叙任することがその国や地域の法令に適合しないと運営者が判断した国と地域の国籍を持つ人、そこに住む人、願い出のときにそこにいる人も、願い出ることができません（「法令に適合しない国と地域」）。

## 受付の停止

2026-11-12 から、叙任の願い出を受けていません。2026-11-12 に利用者が決めました。2026-11-22 から効力を持つ改めた規程（日本に住み日本にいる人に限ること、イタリアの国籍を持つ人を除くこと、良識の前提）の前の期間に、日本の外の法令が及ぶおそれが残っていたためです。
2026-11-22 0 時（日本時間）からも、停止を続けます。受付に戻る日は決めていません。授けることに、イタリアの刑法典と 1951 年法律第 178 号がどう及ぶかが、条文からは決まらないためです。2026-11-13 に利用者が法的リスクを限りなく小さくするよう求め、Claude が決めました。
止めるのは受付だけで、この規程と騎士の名簿は残します。
受付を止めているあいだは、叙任の願い出の様式を、issue の様式の一覧に置きません。様式の定義は、受付に戻すときのために、リポジトリの `tools/knighting-form.yml` に残します。2026-11-13 に Claude が決めました。様式を開いたままにすると、受けない願い出を書かせることになるためです。
受付に戻すときは、その理由を[点検の記録](https://github.com/cpsbvbng26-dotcom/nusquama/blob/main/docs/legal-audit-2026-11-12.md)に記したうえで、戻る日を、この節と利用規約で、その日より前に示します。日付が来ただけでは、受付に戻りません。
この停止は、利用規約「悪意がないことと、法令を守ること」の定め（法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します）によります。
このあいだに開かれた願い出の issue には、自動の確認が受付の停止を書き、受けないものとして閉じます。訂正へのリンクは開きません。そのとき自動の確認は、issue の題と本文を短い断りに替え、書き込みを止めます（[個人情報の取り扱い](./privacy.md)「保存の期間」）。
叙任のラベルのない issue でも、このあいだに開かれ、題か本文に願い出の様式の見出しや印を持つものは、同じに扱います。様式を通らずに開かれた issue には、ラベルが付かないためです。2026-11-13 に Claude が決めました。
受付に戻ったあとは、改めた規程で確かめます。このあいだに開かれた issue は開き直さず、願い出る人は新しい issue を開きます。
受けるかどうかを issue を開いた時刻で決めること、閉じる形、新しい issue で願い出ることは、2026-11-12 に Claude が決めました。
受付に戻すことを、日付ではなく、点検の記録に記した決めに結ぶことは、2026-11-13 に Claude が決めました。確かめ終える前に、日付が来ただけで受付に戻らないようにするためです。
停止を決めた 2026-11-12 に、開いている叙任の願い出は 0 件で、騎士の名簿に騎士はいませんでした。停止を続けると決めた 2026-11-13 にも、叙任の願い出の issue は 0 件でした。

## 良識の前提

2026-11-22 から、叙任は、願い出る人が、称号を遊びとして扱う良識ある人であることを前提とします。
この前提は、称号を創作の中でだけ使い、次の決まりを守ることを指します。

- 称号を、この国の中でだけ使う（[利用規約](./terms.md)「称号の扱い」、王国基本法第八条）。
- 称号を、実在の称号・叙勲・団体の記章であるかのように示さない。
- 称号を、履歴書・論文・名刺・公的な書類・商取引・広告に書かない。
- 称号を売らず、称号を使って金銭や物品を集めない。
- 称号を、人をだますために使わない。

これらは、利用規約の「称号の扱い」「してはいけないこと」「悪意がないことと、法令を守ること」と王国基本法第八条の決まりを、称号の使い方として並べたものです。
2026-11-22 から、願い出る人は、様式でこの前提に印を付けます。
願い出た人が書いたことや訂正のリンク先から、この前提に当たらないことがはっきり分かったときは、叙任しません（「断ること」）。
叙任した後に分かったときは、「辞退と取り消し」の定めにより、叙任を取り消します。
取り消すときは、願い出の issue に、当たらなかった決まりだけを短く書き、人を評しません。本人の求めがあれば、その issue を削除します。


## 外国の称号を縛る国

2026-11-22 から、次の表の 18 か国の国籍を持つ人は、日本に住んでいても、ほかの国籍と重ねて持っていても、願い出ることができません。2026-11-12 に Claude が決めました。
表のうちイエメン・オーストリア・ギリシャは、2026-11-13 に Claude が足しました。型で「当たらない」に分けていた称号の条を一つずつ読み直し、型 1 か型 3 に当たる条が見つかったためです。オーストリアは、憲法の第149条が憲法の法律とみなす 1919 年の貴族の廃止の法律を取り寄せて読み、型 3 に当たると読みました。足した国の国籍を持つ人も、2026-11-22 から願い出ることができません。受付は 2026-11-12 から止めているので、さかのぼって断られる人はいません。
表の国の憲法や法律は、取り寄せて読んだ文の上で、次の三つの型のどれかに当たります。

1. 型 1：外国の称号・勲章・栄典・位を受けることを禁じるか、受けるのに国の許しを求める。
2. 型 2：外国の称号などを受けたことに、国籍や市民権の喪失、罰を結び付ける。
3. 型 3：自分のものでない貴族の称号を名乗ることを罰し、騎士の呼び名がその称号と読まれうる。

ヌスクァマは国家ではなく、騎士の呼び名は、どの国の称号でもありません。
それでも、条の文言の上で当たると読む道があるので、次の形で閉じます。
いちばん厳しい読み方を取り、願い出を受けない形にしました。費用がかからず、受けなければその道が閉じるためです。
公務員や国の職にある人だけを縛る条もあります。運営者は願い出た人の職を確かめないので、国籍ごとに受けません。

## 法令に適合しない国と地域

2026-11-29 から、叙任することがその国や地域の法令に適合しないと運営者が判断した国と地域の国籍を持つ人、そこに住む人、願い出のときにそこにいる人は、願い出ることができず、叙任しません。
この定めは、「願い出ることができる人」と「外国の称号を縛る国」の定めに加わります。
運営者がそう判断したときは、その国や地域と理由を、この節に書き足します。書き足すときは、利用規約「変更と終了」の定めに沿って示します。
2026-11-13 の時点で、この定めで除いた国と地域はありません。
2026-11-13 に利用者が求め、Claude が決めました。[運営理念・声明](../MISSION.md)第 8 条が、法令に適合しない国と地域でも叙任しないと述べており、声明はそれ自体で何も定めないので、定めをこの規程に置くためです。

## 騎士の呼び名の使い方

2026-11-22 から、騎士の呼び名は、次の三つを守って使います。2026-11-12 に Claude が決めました。

- ヌスクァマに関わることにだけ使う。
- どの国の貴族の称号・栄典・勲章・位階・尊称としても示さない。
- 公的な場・商取引・法的な場（書類・届出・契約・裁判など）で使わない。

これに反したことが分かったときは、名簿から名を外します。
理由は、取り寄せて読んだ次の条が、称号・栄誉・位を権限なく名乗ることや、許しなく使うことを罰しているためです。

- ドイツ：Strafgesetzbuch (StGB) § 132a
- アルゼンチン：Código Penal de la Nación (Ley 11.179, t.o. 1984) ARTICULO 247
- メキシコ：Código Penal Federal Artículo 250
- イタリア：Codice penale (R.D. 19 ottobre 1930, n. 1398) Art. 498（第 5 段落）、Legge 3 marzo 1951, n. 178 (Ordine al merito della Repubblica) Art. 7（第 2 段落）
- ベルギー：Code pénal Art. 230
- オランダ：Wetboek van Strafrecht Artikel 435
- ノルウェー：Lov om straff (straffeloven) § 165（取り寄せた頁から取れたのは見出しだけです）
- ポルトガル：Código Penal (Decreto-Lei n.º 48/95) Artigo 307（取り寄せた頁から取れたのは見出しだけです）

条の文は、[各国の法令の調べ](../docs/world-law-2026-11-12.md)の「2026-11-12 の続き：当てはめ」に引いています。
この三つを守る使い方が、これらの条の罰する名乗り方や使い方に当たるかは、取り寄せた条文からは決まりません。運営者は、受付を止めています（「受付の停止」）。

## 願い出の手順

サイトを配信する Vercel や、願い出を保管する GitHub が、置かれたものを AI のモデルの学習に使うことがあるため、個人情報が心配な方は、願い出ないでください。この利用は、[個人情報の取り扱い](./privacy.md)に書いてあります。

1. 受付に戻ってから、叙任の願い出の様式で issue を開く（受付を止めているあいだは、様式を置いていない。「受付の停止」）。
2. 訂正への公開のリンクと、何を誤りどう正したかを書く。
3. 誓いのすべてに印を付ける。

願い出た人が同意するのは、願い出の日の版の規程です。その版は、公開のリポジトリの履歴で確かめられます。

本名・住所・所属・連絡先は書きません。

## 運営者が確かめること

- リンク先が公開されていて、訂正であると読めること。
- 訂正したのが、願い出た人自身の誤りであると読めること。
- 他人の個人情報や、他人を傷つける内容が含まれていないこと。
- 様式の誓いのすべてに印があること。
- 訂正のリンク先に、願い出た人が日本の外に住んでいることや、願い出のときに日本の外にいること、イタリアや「外国の称号を縛る国」の国籍を持つこと、16 歳未満であることが、はっきり書かれていないこと。書かれていれば、本人に尋ね、願い出の条件に当たると確かめられなければ叙任しません。

運営者は、訂正の中身が正しいかどうかを判断しません。判断するのは、訂正があったことだけです。

願い出の issue が開かれたり直されたりすると、自動の確認が、様式の誓いの印と、訂正へのリンクが https の URL で受けない先を指さないことを確かめ、結果を issue にコメントします。
自動の確認は、訂正へのリンクを開きません。リンク先を開いて読むのは運営者です。
受けない先は、localhost、.localhost・.local・.internal・.home.arpa・.test・.example・.invalid・.onion で終わる名、数で書いた先、点を含まない名、名や合言葉を含む URL です。どれも公開の頁を指さないためです。
自動の確認は何も決めません。叙任を決めるのは運営者です。

## 確かめないこと

運営者は、国籍・住んでいる国・年齢・本名を確かめません。身分証も求めません。
ヌスクァマは国籍を与えません。騎士は国民ではありません。
年齢・住んでいる国・願い出のときにいる国・イタリアと「外国の称号を縛る国」の国籍を持たないことは、様式の誓いへの印による本人の申告で受けます。
ただし、訂正のリンク先にはっきり書かれていることは、見落としません。
本人として扱うのは、願い出た GitHub のアカウントです。
願い出の条件に当たらなかったことが分かったときは、名簿から名を外します。
16 歳未満の人の願い出だったときは、求めがなくても、その issue も削除します。

## 断ること

次の場合は叙任しません。

- 誤りの訂正ではないもの（宣伝、自己紹介、他人の誤りの指摘など）。
- 確かめられないもの（非公開のもの、リンクが開けないもの）。
- 利用規約の「してはいけないこと」に当たるもの。
- 願い出の条件（年齢・住んでいる国・願い出のときにいる国・国籍）に当たらないことが、訂正のリンク先からはっきり読めるもの。
- 2026-11-12 から、受付に戻るより前に開かれた願い出（「受付の停止」）。
- 2026-11-22 から、「良識の前提」に当たらないことが、願い出た人が書いたことや訂正のリンク先からはっきり読めるもの。

断るときは、決めた一文（「叙任の条件に当たりません。」）だけを issue に書き、人を評しません。本人の求めがあれば、その issue を削除します。

## 名簿

叙任した人は、[騎士の名簿](../KNIGHTS.md)に、叙任の順に載せます。
叙任したときは、運営者が願い出の issue に、名簿の行へのリンクを添えたコメントを書き、issue を「完了」として閉じます。
位は「騎士」の一つだけで、上下はありません（王国基本法第七条）。
名簿には、騎士をアカウント名だけで記します。呼ぶときは「騎士 アカウント名」とし、ほかの呼び名や飾りの語を足しません。

## 辞退と取り消し

騎士は、いつでも名簿からの辞退を求めることができます。理由は要りません。辞退すると、名簿から名を外します。
運営者は、騎士が称号をこの国の外（[利用規約](./terms.md)「称号の扱い」）で使ったとき（王国基本法第八条）や、利用規約に反したときに、叙任を取り消すことがあります。取り消したときは、名簿から名を外します。
王国は誤りを消さないことを旨としますが、人の名は別です。名簿から外した名は、本人の求めがない限り、取り消しの記録にも残しません。

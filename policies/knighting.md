# 叙任の規程

最終更新：2026-11-26。

## 叙任とは

叙任は、創作の中で、騎士の呼び名を贈ることです。
法的な効力・身分・特典・名誉は伴いません。
叙任は、どの国の勲章・栄典・騎士の位を授けるものでもありません。
叙任は無償です。金銭・物品・役務と引き換えにしません（王国基本法第六条）。
叙任では、任命書・証書・記章などの書面や物を発行しません。名簿にアカウント名を載せるだけです。
叙任は、すべてオンラインで行います。願い出は GitHub の issue で受け、叙任したことは、その issue へのコメントと、リポジトリとサイトの騎士の名簿に記します。
叙任の式典や、会って授けることはしません。書状や物を送ることもしません。
ヌスクァマが人に贈るのは、騎士の呼び名だけです。ほかの称号・位・勲章・記章・証書・国籍は、名や形を替えても贈りません。

## 基本法第六条との関係

王国基本法第六条は、叙任の条件を、自分の誤りを一つ公に訂正したことの一つとしています。
この規程の条件は、第六条の条件に加わります。
この規程が条件を足すところは、この規程に従います。
足した条件は、年齢、住む国、願い出のときにいる国、国籍、良識の前提と、受付の停止です。
2026-11-24 からは、「日本の外に出たことがないこと」の条件も、足した条件に加わります。
2026-12-15 からは、「日本の国籍を持つこと」の条件も、足した条件に加わります。
受付に戻ったあとは、「日本の国籍の書類による確かめ」の条件も、足した条件に加わります。
2026-11-29 からは、「法令に適合しない国と地域」の定めも、足した条件に加わります。
2026-12-15 からは、「参加のハードル」の条件も、足した条件に加わります。
2026-12-15 からは、「参加のハードルの続き」の条件も、足した条件に加わります。
第六条の条件を満たしても、この規程の条件を満たさない人は、叙任しません。
2026-11-13 に Claude が決めました。基本法の条を改めずに、第六条の条件だけで叙任されると読まれないためです。

## 願い出ることができる人

自分の誤りを一つ、公に訂正したことがある人です。
訂正は、論文の正誤表、ブログや記事の追記、コードの修正、発言の取り消しなど、公開されていて誰でも確かめられるものに限ります。
16 歳未満の人は願い出ることができません。
住んでいる国の法令が、私人の授ける騎士の称号を受けることや使うことを禁じている人も、願い出ることができません。例として、イタリアの 1951 年法律第 178 号第 8 条は、私人や団体が、名称を問わず騎士の称号などを授けることを禁じています。
2026-11-22 から、願い出ることができるのは、日本に住んでいて、願い出のときに日本にいる人に限ります。イタリアの国籍を持つ人と、「外国の称号を縛る国」の国籍を持つ人を除き、国籍は問いません。
2026-11-22 から、日本の外に住む人は、国籍を問わず願い出ることができません。日本の外の法令を、国ごとに確かめきれないためです。
2026-11-22 から、日本に住んでいても、旅行・出張・留学などで日本の外にいるあいだは、願い出ることができません。外国の法令には、そこに住む人だけでなく、そこにいる人に及ぶものがあるためです。
2026-11-22 から、イタリアの国籍を持つ人は、日本に住んでいても、ほかの国籍と重ねて持っていても、願い出ることができません。理由は二つです。
一つめに、イタリアの国民が日本のミクロネーションの騎士になることは、常識に照らして、そもそも場違いです。
二つめに、イタリアの 1951 年法律第 178 号第 8 条は、称号を使う者も罰し、使う者の罰は授けたのが国外であっても及ぶとしています。同条の終わりの段落が国外として挙げるのは、授けた場所（「quando il conferimento delle onorificenze, decorazioni o distinzioni sia avvenuto all'estero」）だけです。称号を使う場所は書いていません。イタリアの外で称号を使うイタリアの国民にこの罰が及ぶかは、取り寄せた条文からは決まりません。
イタリアの国籍を持つ人を除くのは、運営者の決めです。この決めは願い出る人を除くだけで、同条がどこまで及ぶかを述べるものではありません。
同条の授けた者の罰が運営者に及ぶかは、取り寄せた条文からは決まりません。運営者は、そのために受付を止めています（「受付の停止」、[適法性の説明](./legality.md)「日本の外の法令」）。
旅行などで日本に短く滞在しているだけの人は、日本に住んでいる人に当たりません。
2026-11-24 から、願い出ることができるのは、生まれてから一度も日本の外に出たことがない人に限ります（「日本の外に出たことがないこと」）。
2026-11-29 から、叙任することがその国や地域の法令に適合しないと運営者が判断した国と地域の国籍を持つ人、そこに住む人、願い出のときにそこにいる人も、願い出ることができません（「法令に適合しない国と地域」）。
2026-12-15 から、18 歳未満の人は願い出ることができません（「参加のハードル」）。
2026-12-15 から、訂正は、自分が書いて公開した文の誤りを、前の版が残る場で正したもので、願い出の issue を開いた日の 180 日以上前に公開したものに限ります（「参加のハードルの続き」）。
2026-12-15 から、願い出は、issue を開いた日の 2 年以上前に作られた GitHub のアカウントからだけ受けます。断った願い出のアカウントからは、二度と受けません（「参加のハードルの続き」）。
2026-12-15 から、願い出ることができるのは、日本の国籍を持つ人に限ります。日本の国籍と重ねてイタリアや「外国の称号を縛る国」の国籍を持つ人は、これまでどおり願い出ることができません（「日本の国籍を持つこと」）。

## 受付の停止

2026-11-12 から、叙任の願い出を受けていません。2026-11-12 に利用者が決めました。2026-11-22 に効力を生じた改めた規程（日本に住み日本にいる人に限ること、イタリアの国籍を持つ人を除くこと、良識の前提）の前の期間に、日本の外の法令が及ぶおそれが残っていたためです。
2026-11-22 0 時（日本時間）からも、停止を続けます。受付に戻る日は決めていません。授けることに、イタリアの刑法典と 1951 年法律第 178 号がどう及ぶかが、条文からは決まらないためです。2026-11-13 に利用者が法的リスクを限りなく小さくするよう求め、Claude が決めました。
止めるのは受付だけで、この規程と騎士の名簿は残します。
受付を止めているあいだは、叙任の願い出の様式を、issue の様式の一覧に置きません。様式の定義は、受付に戻すときのために、リポジトリの `tools/knighting-form.yml` に残します。2026-11-13 に Claude が決めました。様式を開いたままにすると、受けない願い出を書かせることになるためです。
受付に戻すときは、その理由を[点検の記録](https://github.com/cpsbvbng26-dotcom/nusquama/blob/main/docs/legal-audit-2026-11-12.md)に記したうえで、戻る日を、この節と利用規約で、その日より前に示します。日付が来ただけでは、受付に戻りません。
この停止は、利用規約「悪意がないことと、法令を守ること」の定め（法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します）によります。
このあいだに開かれた願い出の issue には、自動の確認が受付の停止を書き、受けないものとして閉じます。訂正へのリンクは開きません。そのとき自動の確認は、issue の題と本文を短い断りに替え、書き込みを止めます（[個人情報の取り扱い](./privacy.md)「保存の期間」）。
叙任のラベルのない issue でも、このあいだに開かれ、題か本文に願い出の様式の見出しや印を持つものは、同じに扱います。様式を通らずに開かれた issue には、ラベルが付かないためです。2026-11-13 に Claude が決めました。
受付に戻ったあとは、改めた規程で確かめます。このあいだに開かれた issue は開き直さず、願い出る人は新しい issue を開きます。
受けるかどうかを issue を開いた時刻で決めること、閉じる形、新しい issue で願い出ることは、2026-11-12 に Claude が決めました。
受付に戻すことを、日付ではなく、点検の記録に記した決めに結ぶことは、2026-11-13 に Claude が決めました。確かめ終える前に、日付が来ただけで受付に戻らないようにするためです。
停止を決めた 2026-11-12 に、開いている叙任の願い出は 0 件で、騎士の名簿に騎士はいませんでした。停止を続けると決めた 2026-11-13 にも、叙任の願い出の issue は 0 件でした。
2026-11-26 から、受付に戻すには、点検の記録の表に「イタリアの法令が叙任に及ばないことの確かめ」の行が要ります。
その行は、次の四つの点のすべてについて、叙任に及ばないことを確かめたものでなければなりません。

1. イタリアの 1951 年法律第 178 号第 8 条の授けた者の罰が、刑法典第 7 条第 5 号によって、日本にいる運営者が日本にいる日本の国籍の人に授けることに及ばないこと。
2. 刑法典第 7 条第 1 号と第 8 条（国家の人格に対する罪と、政治上の罪）が、授けることに及ばないこと。
3. 叙任の規程・願い出の issue・名簿がオンラインにあり、イタリアから読めることが、刑法典第 6 条の行いの一部や結果に当たらないこと。
4. 1 から 3 を確かめた一次の出典に、2026-11-26 までに読んでこの点を決めなかった出典のほかのものが、一つ以上あること。

この行がないあいだは、受付の道具（`tools/knighting.js`）は受付に戻らず、検査（`verification/check.js`）は、様式が issue の様式の一覧に戻ったときや、この節の文が弱められたときに落ちます。
同条は「con qualsiasi forma e denominazione」と定め、名称と形を問いません。呼び名や形を替えても、この行は要ります。
2026-11-26 に Claude が決めました。授けることがどこまで罪になるかを並べた結果（[適法性の説明](./legality.md)「イタリアの法令で、授けることがどこまで罪になるか」）、四つの点が条文と取り寄せた文から決まらなかったためです。
2026-11-26 の時点で、これまでに叙任した人は 0 人で、騎士の名簿に騎士はいません。

## 受付に戻すときの場所の確かめ（突き合わせの受付）

人が嘘をつくこと一般を、仕組みは止められません。
仕組みにできるのは、申し立てた人がその場で書けない出どころと突き合わせられる申し立てだけを受け、通らないものと確かめられないものを自動で退けることです。
これを「突き合わせの受付」と呼びます。
受付は止めたままです。この節は、受付に戻すときの条件を定めるもので、受付に戻すことを決めるものではありません。
受付に戻すときは、日本に住んでいることを、願い出る人の申告ではなく、次の確かめで受けます。
願い出る人は ORCID iD を示し、その ORCID の公開の記録が、願い出の issue を開いた GitHub のアカウントにリンクしていなければなりません。
ORCID iD を持たない人からは、受付に戻ったあとも、願い出を受けません。
読むのは、その ORCID の公開の記録のうち、公開の住所の国と、終わりの日のないいまの勤め先と在学先の組織の国だけで、国の符号（ISO 3166）を、それぞれを足した日とともに読みます。国籍は読みません。GitHub のプロフィールは読みません。
これらの項目のどれかが日本の外を指すとき、項目が二つ以上の国を指すとき、日本を指し issue を開く 30 日以上前に足された項目が無いときは、願い出を受けません。
ORCID の項目が日本を指し、issue を開く 30 日以上前に足されたものであるときに限り、日本に住んでいると確かめたとします。
読んだ国と組織は、残さず、書かず、実行の記録にも出しません。issue には、確かめに通ったかどうかだけを書きます。
これで証せるのは、前からある公開の記録が食い違わないことであって、どこに住んでいるかではありません。偽りの記録を 30 日保つ人は、通ることがあります。そのため、事実でない印を付けることを禁じる利用規約の定めと、名簿から名を外す定めは、そのまま保ちます。
ORCID の記録を読むことは、受付に戻すときに、個人情報の取り扱いに目的と読む項目を書き足し、利用規約で前もって示してから始めます。
2026-11-14 に利用者が求め、Claude が決めました。日本に住んでいることを本人の申告だけで受けないようにし、それでも受付を止めたままにするのは、日本の外の法令の一点が条文から決まらないことが変わっていないためです。
2026-12-15 から、この節の 30 日は 365 日です（「参加のハードル」）。

## 参加のハードル

ヌスクァマは個人で運営しているため、参加のハードルを極端に高くしています。
2026-12-15 から、受付に戻ったあとの叙任には、次の六つの条件も加わります。

1. 18 歳未満の人は、願い出ることができません。年齢は、様式の誓いへの印による本人の申告で受けます。
2. 同じ GitHub のアカウントからの願い出は、そのアカウントが前に叙任の願い出の issue を開いた日から 365 日のあいだ受けません。断った願い出も、取り下げた願い出も数えます。受付の停止のあいだ（2026-11-12 から受付に戻るまで）に開かれた願い出は数えません。
3. 叙任は、一年（1 月 1 日から 12 月 31 日まで、日本時間）に 1 人までとします。名簿の叙任の日で数えます。
4. 叙任を決めるのは、願い出の issue を開いた日（日本時間）から 90 日を過ぎてからです。
5. 願い出る人は、様式の「称号を使わない場所」の欄に、この国の称号を書かない場所を、規程の語で三つ以上書きます。規程の語は、履歴書・論文・名刺・公的な書類・学術の場・商取引・広告です（王国基本法第八条、利用規約「称号の扱い」）。
6. 「受付に戻すときの場所の確かめ」の 30 日を、365 日に替えます。日本を指す ORCID の項目は、issue を開く 365 日以上前に足されたものでなければなりません。

この節の日数は、日本時間の日で数え、初めの日（願い出や前の願い出の issue を開いた日、ORCID の項目を足した日）を数えません。たとえば、2026-12-15 に開いた願い出は、2026-12-16 から数えて 90 日が過ぎる 2027-03-15 の終わりまで決めず、決められるのは早くて 2027-03-16 です。同じ日に開いた願い出の次の願い出を受けるのは、2027-12-16 からです。

18 歳は、民法第4条が成年とする年齢です。同条は「年齢十八歳をもって、成年とする。」と定めます。
願い出る人は、様式で利用規約に同意します。同法第5条第1項は「未成年者が法律行為をするには、その法定代理人の同意を得なければならない。」と定め、同条第2項は「前項の規定に反する法律行為は、取り消すことができる。」と定めます。
運営者は、[適法性の説明](./legality.md)「審査の方法と、前提が崩れる道」と同じく、利用規約への同意を、単に権利を得る法律行為（同条第1項ただし書）には当たらないものと読みます。法定代理人の同意を確かめる手立てはないので、18 歳未満の人の願い出を受けません。
1・2・5 は、自動の確認が確かめます。4 は、自動の確認が、叙任を決められる最も早い日をコメントに書きます。3 は、検査（`verification/check.js`）が名簿の行から確かめます。6 は、受付に戻すときに、場所の確かめと同じ手順で確かめます。
2 のために、自動の確認は、GitHub の API から、同じアカウントが開いた叙任の願い出の issue の一覧を受け取ります。一覧には題や本文も含まれますが、使うのは issue の番号（いまの issue を除くため）と開いた時刻だけで、ほかは捨てます。使ったものも残さず、コメントには前の issue の番号も書きません。
様式には、18 歳以上の印と「称号を使わない場所」の欄を足しました。「称号を使わない場所」で尋ねるのは規程の語で、自分のことは書かないよう様式で求めています。
どの条件も、国籍・性別・信条などで人を分けません。場所の決めは、「願い出ることができる人」「外国の称号を縛る国」「法令に適合しない国と地域」のままで、足していません。
受付は止めたままです。この節は、受付に戻ったあとの条件を定めるもので、受付に戻すことを決めるものではありません。
2026-11-19 に利用者がハードルを最大限に上げると決め、Claude が条件を選びました。ひとりの運営者が読み、確かめきれる数の願い出だけを受けるためです。

## 参加のハードルの続き

ヌスクァマは個人で運営しているため、参加のハードルを極端に高くしています。
2026-12-15 から、受付に戻ったあとの叙任には、「参加のハードル」の条件に加えて、次の六つの条件も加わります。

1. 叙任の訂正は、願い出の issue を開いた日（日本時間）の 180 日以上前に公開されたものに限ります。願い出る人は、様式の「訂正を公開した日」の欄に、その日を書きます。
2. 叙任の訂正は、願い出る人が自分で書いて公開した文の誤りを正したものに限ります。他人の文の誤りを指摘したものは数えません。共著の文は、願い出る人が著者に入っていれば数えます。
3. 叙任の訂正は、前の版が残る場でしたものに限ります。場の種類は、下の表の三つです。誤りの元の文と直した文の両方を、第三者が確かめられなければなりません。
4. 願い出の issue を開いた GitHub のアカウントは、issue を開いた日の 2 年以上前に作られたものでなければなりません。
5. 叙任は、2 年に 1 人までとします。「参加のハードル」の 3 の一年に 1 人までを、これに替えます。名簿の叙任の日で数え、前の叙任の日から 2 年が過ぎるまで、次の叙任をしません。
6. 断った願い出の GitHub のアカウントからは、二度と叙任の願い出を受けません。取り下げた願い出は、これまでどおり「参加のハードル」の 2 の 365 日のあいだだけ数えます。

| 場の種類 | 自動の確認が受けるリンクの形 | 前の版が残るところ |
| --- | --- | --- |
| Git の履歴 | GitHub のコミットとプルリクエスト、GitLab のコミットとマージリクエスト、Codeberg のコミットとプルリクエストの頁 | 差分に直す前の行と直した後の行が並び、前の版もリポジトリの履歴に残る |
| 版を分けて残す登録 | DOI の頁、Zenodo の記録の頁、arXiv の版の番号の付いた頁 | 版ごとに識別子が付き、前の版も公開に残る |
| 正誤表の頁 | 正誤表に付いた DOI の頁 | 正誤表が元の文と直した文を並べ、元の文の頁も残る |

この節の日と年も、日本時間の日で数え、初めの日（訂正を公開した日、アカウントが作られた日、前の叙任の日）を数えません。
2 年は、初めの日の次の日から数えて、2 年後の同じ月日の前の日の終わりに過ぎます。2 年後に同じ月日がない（初めの日の次の日が 2 月 29 日の）ときは、2 年後の 2 月の終わりに過ぎます。
2 年に 1 人までの 2 年は、暦の上の区切り（年の初めから 2 年ごとなど）ではなく、前の叙任の日から数えます。区切りの境で続けて叙任しないためです。

### 受ける書類

## 願い出の手順

サイトを配信する Vercel や、願い出を保管する GitHub が、置かれたものを AI のモデルの学習に使うことがあるため、個人情報が心配な方は、願い出ないでください。この利用は、[個人情報の取り扱い](./privacy.md)に書いてあります。

1. 受付に戻ってから、叙任の願い出の様式で issue を開く（受付を止めているあいだは、様式を置いていない。「受付の停止」）。
2. 訂正への公開のリンクと、何を誤りどう正したかを書く。
3. 誓いのすべてに印を付ける。

願い出た人が同意するのは、願い出の日の版の規程です。その版は、公開のリポジトリの履歴で確かめられます。

本名・住所・所属・連絡先は書きません。

2026-12-15 から、様式の「称号を使わない場所」の欄にも書き、18 歳以上の印も付けます（「参加のハードル」）。

2026-12-15 から、様式の「訂正を公開した日」の欄にも書き、誤りの元の文が自分の書いた文である印も付けます（「参加のハードルの続き」）。

2026-12-15 から、日本の国籍を持つ印も付けます（「日本の国籍を持つこと」）。

受付に戻ったあとは、「日本の国籍の書類による確かめ」を受ける印も付けます。運営者が招く非公開のリポジトリに、戸籍の証明書の画像を置きます（「日本の国籍の書類による確かめ」）。

## 運営者が確かめること

- リンク先が公開されていて、訂正であると読めること。
- 訂正したのが、願い出た人自身の誤りであると読めること。
- 他人の個人情報や、他人を傷つける内容が含まれていないこと。
- 様式の誓いのすべてに印があること。
- 2026-12-15 から、リンク先で、公開した日が様式の「訂正を公開した日」と合うこと、誤りの元の文と直した文の両方が見られること、元の文が願い出た人の書いた文（共著の文では、願い出た人が著者に入っているもの）であると読めること（「参加のハードルの続き」）。
- 訂正のリンク先に、願い出た人が日本の外に住んでいることや、願い出のときに日本の外にいること、イタリアや「外国の称号を縛る国」の国籍を持つこと、16 歳未満であることが、はっきり書かれていないこと。書かれていれば、本人に尋ね、願い出の条件に当たると確かめられなければ叙任しません。
- 2026-12-15 から、訂正のリンク先に、願い出た人が日本の国籍を持たないことが、はっきり書かれていないこと。書かれていれば、本人に尋ね、日本の国籍を持つと確かめられなければ叙任しません（「日本の国籍を持つこと」）。
- 受付に戻ったあと、「日本の国籍の書類による確かめ」の結果が「確かめた」であること。運営者は、その一行を願い出の issue に記すまで、叙任を決めません。

運営者は、訂正の中身が正しいかどうかを判断しません。判断するのは、訂正があったことだけです。

願い出の issue が開かれたり直されたりすると、自動の確認が、様式の誓いの印と、訂正へのリンクが https の URL で受けない先を指さないことを確かめ、結果を issue にコメントします。
自動の確認は、訂正へのリンクを開きません。リンク先を開いて読むのは運営者です。
受けない先は、localhost、.localhost・.local・.internal・.home.arpa・.test・.example・.invalid・.onion で終わる名、数で書いた先、点を含まない名、名や合言葉を含む URL です。どれも公開の頁を指さないためです。

2026-12-15 から、自動の確認は、18 歳以上の印、「称号を使わない場所」の答え、同じアカウントの前の願い出の日も確かめ、叙任を決められる最も早い日を書きます（「参加のハードル」）。
2026-12-15 から、自動の確認は、誤りの元の文が自分の書いた文である印、訂正を公開した日、訂正へのリンクが前の版が残る場の形か、アカウントの作られた日、同じアカウントの断った願い出も確かめます（「参加のハードルの続き」）。
2026-12-15 から、自動の確認は、日本の国籍を持つ印も確かめます（「日本の国籍を持つこと」）。

年齢・住んでいる国・願い出のときにいる国・イタリアと「外国の称号を縛る国」の国籍を持たないことは、様式の誓いへの印による本人の申告で受けます。
2026-11-24 から、生まれてから一度も日本の外に出たことがないことも、様式の誓いへの印による本人の申告で受けます。旅券などの書類は求めません（「日本の外に出たことがないこと」）。
2026-12-15 から、日本の国籍を持つことも、様式の誓いへの印による本人の申告で受けます。受付に戻ったあとは、これに「日本の国籍の書類による確かめ」が加わります。旅券・住民票・個人番号カードは求めません（「日本の国籍を持つこと」）。

## 断ること

次の場合は叙任しません。

- 誤りの訂正ではないもの（宣伝、自己紹介、他人の誤りの指摘など）。
- 確かめられないもの（非公開のもの、リンクが開けないもの）。
- 利用規約の「してはいけないこと」に当たるもの。
- 願い出の条件（年齢・住んでいる国・願い出のときにいる国・国籍）に当たらないことが、訂正のリンク先からはっきり読めるもの。
- 2026-11-12 から、受付に戻るより前に開かれた願い出（「受付の停止」）。
- 2026-11-22 から、「良識の前提」に当たらないことが、願い出た人が書いたことや訂正のリンク先からはっきり読めるもの。
- 2026-11-24 から、「日本の外に出たことがないこと」の印のないもの。
- 2026-12-15 から、「参加のハードル」の条件に当たらないもの。
- 様式の誓いのうち、必ず印を付けるものに印のないもの。
- 2026-11-29 から、「法令に適合しない国と地域」に当たることが、訂正のリンク先からはっきり読めるもの。
- 2026-12-15 から、「参加のハードルの続き」の条件に当たらないもの。
- 2026-12-15 から、「日本の国籍を持つこと」の印のないもの。
- 受付に戻ったあと、「日本の国籍の書類による確かめ」で確かめられなかったもの。

断るときは、決めた一文（「叙任の条件に当たりません。」）だけを issue に書き、人を評しません。本人の求めがあれば、その issue を削除します。
2026-12-15 から、断った願い出の issue には、ラベル「断った」を付けます。そのアカウントからは、二度と叙任の願い出を受けません（「参加のハードルの続き」）。
受付の停止のあいだに閉じた願い出と、2 年に 1 人までのために断った願い出は、この断った願い出に数えません。

## 名簿

叙任した人は、[騎士の名簿](../KNIGHTS.md)に、叙任の順に載せます。
叙任したときは、運営者が願い出の issue に、名簿の行へのリンクを添えたコメントを書き、issue を「完了」として閉じます。
位は「騎士」の一つだけで、上下はありません（王国基本法第七条）。
名簿には、騎士をアカウント名だけで記します。呼ぶときは「騎士 アカウント名」とし、ほかの呼び名や飾りの語を足しません。

## 辞退と取り消し

騎士は、いつでも名簿からの辞退を求めることができます。理由は要りません。辞退すると、名簿から名を外します。
運営者は、騎士が称号をこの国の外（[利用規約](./terms.md)「称号の扱い」）で使ったとき（王国基本法第八条）や、利用規約に反したときに、叙任を取り消すことがあります。取り消したときは、名簿から名を外します。
王国は誤りを消さないことを旨としますが、人の名は別です。名簿から外した名は、本人の求めがない限り、取り消しの記録にも残しません。

# 名称と権利

最終更新：2026-11-18。

## 名前の由来

- **ヌスクァマ（Nusquama）**：ラテン語の副詞 nusquam（どこにも…ない）を名の形にした呼び名です。トマス・モアは、1516 年 9 月 3 日付のエラスムスへの手紙で、のちの『ユートピア』を「ヌスクァマ」と呼びました。改める前の文は[王の正誤表](../ERRATA.md)にあります。
- **ネモ（Nemo）**：ラテン語で「誰でもない者」。
- **無何有（むかう）**：『荘子』の「無何有の郷」から取った、何もない所を指す古い言葉です。
- **騎士王（Rex Eques）**：騎士と王を合わせた語です。

これらはどれも一般の言葉や古典に由来するもので、特定の作品・団体・人物の名を借りたものではありません。
『ユートピア』と『海底二万里』、アーサー王伝説を題材とする作品や、その登場人物・絵・紋章とは関係がありません。
ヌスクァマは、似た名を持つほかのミクロネーション（たとえば「Nusquamia」）とは関係がありません。

## 国章

国章は、運営者が長方形と多角形だけで描いたものです。
実在の国家・王室・騎士団・勲章・大学・企業の紋章や記章を写したものではありません。

## ライセンス

ヌスクァマの文と国章は、CC BY 4.0 で公開しています（[LICENSE](../LICENSE)）。
検証のために引いたり記したりした他人の文は、CC BY 4.0 の対象ではなく、それぞれの権利者のものです。
表示を守れば、誰でも複製・改変・再配布できます。
ただし、CC BY 4.0 は、ヌスクァマの称号に効力を与えるものでも、国章を実在の記章として使うことを認めるものでもありません。
他人が国章をあしらって作った物は、ヌスクァマとは関係がありません。ヌスクァマが作ったものでも、認めたものでも、贈ったものでもありません。ライセンスはこのまま変えません。
CC BY 4.0 が許すのは、著作権の及ぶ範囲のことだけです。商標などのほかの権利や、ほかの法令による制限には及びません。
国章や称号を、実在の団体の記章や、公的な称号であるかのように使ってはいけません（[利用規約](./terms.md)）。そうした使い方は、著作権とは別に、法令（軽犯罪法第1条第15号など）に触れるおそれがあります。
文と国章は、運営者の求めにより Claude Code で書いたものです。言語モデルを使って作ったものに、著作権がどこまで及ぶかは定まっていません。CC BY 4.0 は、権利が及ぶ範囲で許すものです。

## 権利者の方へ

ヌスクァマの名や国章、サイトの文が権利を侵していると考える権利者は、運営者に知らせることができます。
商標や紛らわしい名、文や国章の著作権、肖像、そのほかの権利が対象です。
知らせは、[権利者の知らせ](https://github.com/cpsbvbng26-dotcom/nusquama/issues/new?template=rights.yml)の様式で出します。
自分についての記載の訂正や削除は、これまでどおり[削除・訂正・辞退の求め](./requests.md)の様式でも受けます。
公開の場で書けない事情があるときは、[削除・訂正・辞退の求め](./requests.md)の「公開できない求め」の手順によります。
運営者は、すべての知らせを読みます。
権利が確かめられたときは、運営者が名を変えるか、その文や国章を使うのをやめます。
決めたことは issue に書き、変えたことは[年表](../README.md)と官報に記します。
名としるしの扱い、調べた記録、知らせが来たときの手順は、[名称と権利](./names.md)の「名称と商標」にあります。

### 名の使い方

ヌスクァマは創作であり、遊びです。
名は、この創作と、そのサイトと記録を指すためだけに使います。
ヌスクァマは何も売りません。
称号を売らず、寄付を受けず、広告を出しません。
商標法第2条第1項は、商標を使い方で定めます。業として商品を生産し、証明し、または譲渡する者がその商品について使う標章と、業として役務を提供し、または証明する者がその役務について使う標章です。
業として商品も役務も扱わないヌスクァマの名の使い方は、この定義の外にあると考えます。
この読み方は、点検の記録に移した段落（[王の正誤表](../ERRATA.md)の **52**）と、[適法性の説明](./legality.md)の「商標と表示（商標法第25条、不正競争防止法第2条第1項第1号・第2号）」によります。

### 登録の表示を付けないこと

サイトは、自分の名としるしに、®・™・「登録商標」・"registered trademark" を付けません。どれも登録していないからです。
商標法第74条第1号は、登録商標以外の商標の使用をする場合に、その商標に商標登録表示またはこれと紛らわしい表示を付する行為を禁じています。
同法第73条は、商標登録表示を、その商標が登録商標である旨の表示と定めています。

### 国旗と国章

国旗と国章は、実在のどの国の国旗や紋章でも、国際機関の標章でもありません。それらを写してもいません。
ファイルに描いてあるのは、紺 `#14213d`・金 `#c9a227`・明るい金 `#e8cf74`・深い紺 `#0b1428` の長方形と多角形だけです。
国旗は、紺の地に金の縁、黄金比の矩形、三つの角石です。帯・十字・星・月の形はありません。
国章は、金の縁の紺の盾に、黄金比の矩形と三つの角石、切っ先を下に向けた剣です。剣の鍔と刃は、十字の形に交わります。色は金と明るい金です。
2026-11-18 に、Claude が、配っているすべての画像の色を数えました。SVG の色は上の色だけで、PNG と ICO の画素にも、赤と白はありませんでした。
白地に赤の十字や赤の新月の形は、どの画像にもありません。そのため、赤十字の標章及び名称等の使用の制限に関する法律の条文は取り寄せていません。
商標法第4条第1項第1号から第5号は、登録できない商標を挙げています。国旗・菊花紋章・勲章・褒章・外国の国旗、指定された外国の紋章や記章、指定された国際機関の標章、赤十字の標章や名称と国民保護の特殊標章、指定された監督用や証明用の印章や記号と、同じか似た商標です。
不正競争防止法第16条は、経済産業省令で定める外国の国旗や紋章などと同じか似たものを、商標として使うことなどを禁じています。
同法第17条は、国際機関と関係があると誤認させる方法で、その標章と同じか似たものを商標として使うことなどを禁じています。
ヌスクァマは、商標の登録を出願しません。
国旗と国章を商標として使わず、何も売りません。
経済産業大臣の指定と経済産業省令が定める紋章・記章・標章の一覧は、取り寄せていません。突き合わせたのは、ファイルの形と色です。

### 知らせが来たとき

1. 知らせは、上の「権利者の方へ」にある権利者の知らせの様式か、[削除・訂正・辞退の求め](./requests.md)の「公開できない求め」の手順で届きます。
2. 運営者は、それを読みます。
3. 決めるまでのあいだ、運営者は、名が出る所に、ヌスクァマがその権利者と関わりがないことの断り書きを足すことがあります。
4. 権利が確かめられたときは、運営者が、サイトの題と文、Vercel のプロジェクトの名とサイトのアドレス、リポジトリの名、様式、README を変えます。
5. 運営者は、MicroWiki の記事と X のアカウントの名も、それぞれのサービスが許す範囲で変えます。
6. 書き換えないものもあります。王の正誤表の行、年表の行、過去の官報の号、リポジトリの履歴は、古い名のまま残ります。サイトがそれらを示す所には、名を変えたことの断り書きを添えます。
7. 変えたことは、どれも[年表](../README.md)と官報に記します。決めたことは issue に書きます。
8. 権利が確かめられないときも、同じ所に理由を書きます。

## 誤りの知らせで扱うもの

王の書いた文の誤りの知らせは、GitHub（米国）の公開の issue で受けます（[誤りの知らせ](https://github.com/cpsbvbng26-dotcom/nusquama/issues/new?template=error.yml)の様式）。
知らせでは、GitHub のアカウント名と、知らせに書かれたことを扱います。
これらは issue で公開されます。王の正誤表には、知らせた人の名を書きません。

2026-12-01 から、誤りの知らせは、日本にいる人からだけ受けます。そのために、知らせる人の ORCID iD を様式で尋ね、その ORCID の公開の記録のうち、GitHub のアカウントへのリンク、公開の住所の国、終わりの日のないいまの勤め先と在学先の組織の国（それぞれを足した日とともに）だけを読みます。国の符号（ISO）だけを読み、国籍は読みません。
日本を指す項目が issue を開く 30 日以上前からあり、ほかの国を指す項目がないときに限り、日本にいると確かめたとします。確かめられない知らせは受け付けず、ラベルと決まった文のコメントを付けます。issue は閉じません。

2026-12-15 から、その日以後に開かれた知らせは、様式の「確かめた先」の欄に空白を除いて 6 文字以上が書かれていなければ受け付けず、ラベル「source not given」と決まった文のコメントを付けます。issue は閉じません。この欄は前から様式にあり、新しく集める情報はありません。
読んだ国も組織も、保存せず、コメントにも実行の記録にも書きません。書くのは、確かめられたかどうかだけです。
2026-12-15 から、その日以後に開かれた知らせは、同じ GitHub のアカウントから 30 日に一件までです。そのアカウントが前に誤りの知らせを開いた日を数えずに 30 日が過ぎるまでは受け付けず、ラベル「one per 30 days」と決まった文のコメントを付けます。issue は閉じません。数えるのは、ラベル「誤り」の付いた issue のすべてで、受け付けなかった知らせも数えます。

削除・訂正・辞退・権利・個人の情報・同意の求めには、この限りは掛かりません。安全の問題の知らせにも、掛かりません。

## 保存の期間

名簿の記載は、辞退の求めがあるまで残します。
断った願い出の issue は、断った一文を示すために残します。本人の求めがあれば削除します。
2026-12-15 から、断った願い出の issue には、ラベル「断った」を付けます。このラベルの付いた issue が、そのアカウントから二度と叙任の願い出を受けないことの記録です。本人の求めでその issue を削除したときは、記録も無くなります。断ったアカウントの一覧を、ほかに作りません（[叙任の規程](./knighting.md)「参加のハードルの続き」）。
受付を止めているあいだに叙任の願い出として届いた issue は、自動の確認が、題と本文を短い断りに替えて閉じ、書き込みを止めます。運営者は、届いた中身を名簿にもほかの場所にも写しません。替えたあとの issue に示されるのは、開いた人のアカウント名と開いた日と断りだけです。
替える前の題と本文は、GitHub が issue の編集の履歴に残します。その削除は、削除の求めに応じて行います。
自動の確認は、issue の本文を実行の記録（GitHub Actions のログ）に写しません。
issue は、削除の求めがあれば、運営者が issue を削除するか、本文を空にしたうえで編集の履歴からも前の版を消します。
リポジトリの履歴と、ほかの者がすでに写したものには、記載が残ることがあります。
GitHub は、issue が開かれたときや書き込まれたときに、その動きを受け取る設定のアカウントへ通知を送ります。
通知は、受け取る人の設定によって電子メールでも届きます。電子メールの通知は、issue の中身の写しを含みます。
受け取るアカウントには、運営者のアカウントも含まれることがあります。
その写しの扱いは、GitHub の利用規約とプライバシーステートメントに従います。
GitHub の説明書は、受信箱の通知のうち保存の印のないものを 3 か月保つと書いています。
issue の題と本文を替えたり、issue を削除したりしたときに、すでに届いた通知の写しが消えるとは、取り寄せた GitHub の説明書は書いていません。

## 安全のための措置

扱う個人データは、公開の issue と騎士の名簿にあるものだけです。
GitHub の通知は、issue の中身の写しを、通知を受け取るアカウントの持ち主に届けることがあります（上の「保存の期間」）。運営者もその一人であることがあります。
運営者は、これとは別に、ほかの場所に集めず、写しも作りません。
名簿とサイトを変えられるのは、リポジトリの持ち主である運営者の GitHub アカウントだけです。
そのアカウントは、二段階認証を使っています。
名簿やサイトの変更は、リポジトリの公開の履歴にすべて残り、検査を通してから入ります。
サイトは cookie もデータベースも持たず、閲覧者から何も集めません。
issue が開かれたり直されたりしたときと、issue にコメントが書かれたり直されたりしたときは、自動の確認（`tools/personal.js`）が、題と本文の中の連絡先の形をした文字を数えます。
見る形は、メールアドレス、電話番号、郵便番号、4 桁の組を四つ並べた番号、4 桁の組を三つ並べた番号の五つです。決まった形を文字の上で見るだけで、言語モデルも外のサービスも使いません。
書いたのが運営者でないときは、見つけた文字だけを「［伏せた］」の語に替え、ラベル「伏せた」を付け、種類ごとの数だけを書いたコメントを置きます。issue は閉じず、書き込みも止めません。受付の停止のあいだに叙任の願い出として届いた issue は、「保存の期間」のとおり、題と本文を断りに替えます。
見つけた文字は、コメントにも実行の記録にも書きません。記録に出すのは、決まった語と数だけです。替える前の文は、GitHub が編集の履歴に残し、その削除は、削除の求めに応じて行います。
PR の会話は、この確認の外にあり、運営者が読みます。
外国で扱われることへの備えは、上の「第三者への提供と外国にある事業者」に書いてあります。

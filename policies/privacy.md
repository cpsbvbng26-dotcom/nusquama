# 個人情報の取り扱い

最終更新：2026-11-08。

## 取り扱う者

ヌスクァマの運営者です。運営者は、GitHub のアカウント cpsbvbng26-dotcom の持ち主である個人です。
運営者は、日本の個人情報保護法の定めに沿って取り扱います。

## サイトが集めるもの

サイトは、cookie を使わず、アクセス解析も広告も置いていません。
サイトの頁は、ほかのサーバーへ何も要求しません。
サイトは Vercel（米国）が配信します。Vercel は、配信のために、閲覧の要求を IP アドレスを含めて処理し、記録することがあります。その扱いは、Vercel 自身の個人情報の方針に従います。

## 叙任の願い出で扱うもの

叙任の願い出は、GitHub（米国）の公開の issue で受けます。
願い出では、次のものを扱います。

- GitHub のアカウント名
- 訂正への公開のリンク
- 何を誤り、どう正したかの説明

これらは issue で公開され、叙任された人については、GitHub のアカウント名・叙任の日・正した誤りの要約・願い出へのリンクを[騎士の名簿](../KNIGHTS.md)に載せます。
本名・住所・所属・連絡先は求めません。様式でも、書かないよう求めています。
ただし、訂正へのリンクの先に本名や所属が書かれている場合は、名簿と issue によって、アカウント名とその人が結び付いて公開されます。
issue の扱いは、GitHub の利用規約とプライバシーステートメントにも従います。

## 利用の目的

叙任を判断すること、名簿を載せること、求めに応じること。これ以外には使いません。

## 第三者への提供と外国にある事業者

上の情報は、GitHub と Vercel（どちらも米国）のサービスの上で公開されます。
願い出る人は、様式の誓いで、公開と、これらのサービスで扱われることに同意します。
米国には、日本の個人情報保護法に当たる、個人情報を包括して扱う連邦の法律はありません。GitHub と Vercel は、それぞれのプライバシーステートメントや方針に沿って情報を扱います。
法令に基づく場合を除き、これ以外に第三者へ渡すことはありません。

## 保存の期間

名簿の記載は、辞退の求めがあるまで残します。
issue は、削除の求めがあれば、運営者が issue を削除するか、本文を空にしたうえで編集の履歴からも前の版を消します。
リポジトリの履歴と、ほかの者がすでに写したものには、記載が残ることがあります。

## 開示・訂正・利用停止・削除の求め

自分についての記載は、いつでも訂正・削除・名簿からの辞退を求めることができます。
保有個人データの開示と利用停止にも応じます。
手続きは[削除・訂正・辞退の求め](./requests.md)にあります。費用はかかりません。
個人情報保護法第32条が本人に知らせるよう求める事項のうち、この頁に書いていないものは、求めがあれば遅滞なく答えます。

## 未成年

16 歳未満の人は、叙任を願い出ることができません。
個人情報保護委員会の Q&A は、一般に 12 歳から 15 歳までの年齢以下の子どもについて、法定代理人などの同意が要るとしています。ヌスクァマはその同意を確かめる手立てを持たないので、16 歳未満の願い出を受けません。
16 歳未満の人の願い出だと分かったときは、求めがなくても、名簿から名を外し、その issue を削除します。

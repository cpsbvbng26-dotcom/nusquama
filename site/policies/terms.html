無何有騎士王国ヌスクァマEnglish

これは創作であり、遊びです。ヌスクァマは国家ではなく、いかなる実在の国家・王室・騎士団・叙勲・称号とも関係がありません。ここで授ける称号に、法的な効力はありません。

利用規約

最終更新：2026-11-09。

この規約が及ぶ人

この規約は、ヌスクァマのサイトとリポジトリを読む人、叙任を願い出る人、騎士の名簿に名がある人のすべてに及びます。叙任を願い出る人は、願い出の様式で、その日の版のこの規約に同意します。サイトやリポジトリを読むことを、何かへの同意とはみなしません。読む人にとって、この規約はヌスクァマの仕組みを示すもので、双方が負うものは法令が定めます。免責事項・個人情報の取り扱い・叙任の規程・削除・訂正・辞退の求め・名称と権利も、この規約の一部です。ヌスクァマが法令に触れないと運営者が考える理由は、適法性の説明に法令ごとに書いてあります。適法性の説明は、規約の一部ではなく、運営者の理解の説明です。

ヌスクァマとは何か

ヌスクァマは、運営者が遊びとして書いている創作です。国家ではありません。領土・国民・政府・通貨・旅券・国籍を持たず、主権も領有も主張しません。国際法上の国家ではなく、国家としての承認を求めず、どの国とも外交の関係を結びません。実在の国家・王室・騎士団・叙勲・栄典・称号のいずれとも関係がなく、それらを名乗るものでも、それらに代わるものでもありません。通貨・点数・引換券・電子的な価値・旅券・身分証・証明書のどれも発行しません。「騎士王ネモ一世」は、運営者が創作の中で演じる役の名です。

悪意がないことと、法令を守ること

ヌスクァマに悪意はありません。人をだますことも、誰かを害することも、目的にしていません。運営者は、日本の法令と、使っているサービスの規約を守って運営します。法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します。適法かどうか迷う事柄は、行わないほうを選びます。

称号の扱い

ヌスクァマの称号（騎士王・騎士・正誤表騎士団の団員）は、創作の中の言葉です。どの国の法令に定められた称号でもなく、法的な効力も、身分も、特典もありません。称号は、この国の中でだけ使います。この国の中とは、このリポジトリとサイト、そして運営者がこの国を紹介するために自ら書いた記事や投稿（README「ほかの場所」に挙げたもの）を指します。ヌスクァマは、勲章・記章・制服・証書などの物を作らず、配りません。官公職・位階勲等・学位・その他法令により定められた称号と誤認されるように使うことは、してはいけません。履歴書・論文・名刺・公的な書類・商取引・広告に、ヌスクァマの称号を書いてはいけません。

費用

ヌスクァマは、誰からも料金を取りません。称号を売らず、寄付を受けず、広告を出さず、何も販売しません。叙任の願い出にも、名簿への記載にも、費用はかかりません。ヌスクァマの称号を有料で授けると称する者がいても、ヌスクァマとは関係がありません。

してはいけないこと

  • 他人の誤りや、自分のものでない訂正で叙任を願い出ること。
  • 他人の個人情報（本名・住所・連絡先・写真など）を issue に書くこと。
  • 他人を中傷し、脅し、または嫌がらせをすること。
  • ヌスクァマの称号や国章を、実在の称号・叙勲・団体の記章であるかのように使うこと。
  • ヌスクァマの名で、金銭や物品を集めること。
  • サイトや様式を壊そうとすること。
  • 願い出の様式で、事実でないことに印を付けること。例として、年齢、住んでいる国、訂正が自分の誤りであることがあります。

運営者は、これらに当たる願い出を断り、issue を閉じ、名簿から名を外すことがあります。印が事実でないと分かったときは、運営者は、知った時点で名簿から名を外します。2026-11-22 からは、同じ GitHub アカウントからのその後の願い出を断ることもあります。運営者は、印を信頼して受け、確かめません。事実でない印で叙任された人がいても、ヌスクァマが願い出を受けないとする国に住む人を受けたことにはなりません。印は、本人の求めで削除するまで、公開の issue に残るので、何にいつ印を付けたかを示せます。願い出た人に、違約金や、法令が定める以上の損害の賠償を求めることはありません。

保証しないこと

サイトとリポジトリは、現状のまま提供します。いつでも読めることも、内容に誤りがないことも保証しません。詳しくは免責事項にあります。

変更と終了

この規約とほかの規程は、変わることがあります。各頁の日付が最後の変更を示し、過去の版は公開のリポジトリに残ります。読む人や騎士に不利になる変更は、変える内容と効力の生じる日を、効力の生じる前にこの頁で示します。予告：2026-11-22 から、叙任を願い出ることができるのは、日本に住んでいて、願い出のときに日本にいる人に限ります。国籍は問いません（叙任の規程「願い出ることができる人」）。予告：2026-11-22 から、事実でない印を付けた GitHub アカウントからのその後の願い出を断ることがあります（「してはいけないこと」）。どの変更によっても、料金は生じません。ヌスクァマは、予告なく終わることがあります。終わる場合も、騎士の名簿は、本人から辞退の求めがない限り、リポジトリに残します。

準拠法と紛争

この規約は日本法に準拠します。この規約のどの定めも、法令が制限を認めない権利を制限しません。紛争は、示談による解決を優先します。運営者は、訴えを起こす前に、まず相手方と話し合います。話し合いは、issue か、削除・訂正・辞退の求めの「公開できない求め」に沿った連絡で行います。相手方から示談の申し出があれば、運営者は誠実に応じます。示談で解決しない紛争は、訴額に応じて、宇都宮地方裁判所または宇都宮簡易裁判所を、第一審の専属的合意管轄裁判所とします。これは、消費者や日本国外の人が、法令によって別の裁判所で訴える権利を奪うものではありません。

GitHub と Vercel の規約

ヌスクァマは、米国の二つのサービスの上で動いています。願い出と求めは GitHub の issue で受け、サイトは Vercel が配信します。それぞれの規約も、この規約と並んで適用されます。この規約は GitHub や Vercel を拘束せず、GitHub や Vercel との争いは、それぞれの規約に従います。二つのサービスの規約は、2026-11-09 に原文で読みました。GitHub の利用規約（2026-04-27 発効）、許容される利用の方針、プライバシーステートメント（2026-04-27 発効）と、Vercel の利用規約（2026-10-19 更新）、許容される利用の方針（2026-04-21 更新）、プライバシーの通知（2026-06-01 更新）です。ヌスクァマを使う人に関わる定めは、次のとおりです。

  • GitHub が受け入れる利用者は、13 歳以上の人です（GitHub の利用規約 B.3）。叙任を願い出ることができるのは、それより上の 16 歳以上の人です。
  • issue に書くものは、GitHub の許容される利用の方針に従う必要があります。スパム、嫌がらせ、他人の私的な情報についての定めがあります（GitHub の利用規約 C）。
  • GitHub は、法令や規約に反する内容を拒んだり削除したりでき、アカウントを閉じることもできます（GitHub の利用規約 D.2・M.3）。
  • 公開のリポジトリとその issue の内容は、誰でも見ることができます。GitHub の規約は、ほかの人による適法な利用を制限していません（GitHub の利用規約 D.5・D.8）。GitHub とその関連会社は、その内容を保存し、複製し、表示し、AI の機能や関連会社のモデルの学習に使うことができます（GitHub の利用規約 D.4）。公開の内容について、これを止める設定はありません（GitHub の利用規約 J.3）。

  • Hobby プランでは、Vercel は、配信する内容を AI と機械学習のモデルの学習に使い、そのために第三者に渡すことができます。アカウントのチームの設定でこれを止めたときは別です（Vercel の利用規約 第 3 条）。

  • GitHub と Vercel は、どちらもサービスを「現状のまま」保証なしに提供し、自らの責任を限っています（GitHub の利用規約 O・P、Vercel の利用規約 第 20 条・第 21 条）。どちらの規約も米国カリフォルニア州の法に従い、裁判所はサンフランシスコの裁判所です。Vercel の規約は仲裁も定めています（GitHub の利用規約 S.1、Vercel の利用規約 第 23 条）。

これは創作であり、遊びです。ヌスクァマは国家ではなく、いかなる実在の国家・王室・騎士団・叙勲・称号とも関係がありません。ここで贈る騎士の呼び名は、勲章・栄典・騎士の位ではなく、法的な効力もありません。

叙任の規程

最終更新：2026-11-12。

叙任とは

叙任は、創作の中で、騎士の呼び名を贈ることです。法的な効力・身分・特典・名誉は伴いません。叙任は、どの国の勲章・栄典・騎士の位を授けるものでもありません。叙任は無償です。金銭・物品・役務と引き換えにしません（王国基本法第六条）。叙任では、任命書・証書・記章などの書面や物を発行しません。名簿にアカウント名を載せるだけです。

願い出ることができる人

自分の誤りを一つ、公に訂正したことがある人です。訂正は、論文の正誤表、ブログや記事の追記、コードの修正、発言の取り消しなど、公開されていて誰でも確かめられるものに限ります。16 歳未満の人は願い出ることができません。住んでいる国の法令が、私人の授ける騎士の称号を受けることや使うことを禁じている人も、願い出ることができません。例として、イタリアの 1951 年法律第 178 号第 8 条は、私人や団体が、名称を問わず騎士の称号などを授けることを禁じています。2026-11-22 から、願い出ることができるのは、日本に住んでいて、願い出のときに日本にいる人に限ります。イタリアの国籍を持つ人を除き、国籍は問いません。2026-11-22 から、日本の外に住む人は、国籍を問わず願い出ることができません。日本の外の法令を、国ごとに確かめきれないためです。2026-11-22 から、日本に住んでいても、旅行・出張・留学などで日本の外にいるあいだは、願い出ることができません。外国の法令には、そこに住む人だけでなく、そこにいる人に及ぶものがあるためです。2026-11-22 から、イタリアの国籍を持つ人は、日本に住んでいても、ほかの国籍と重ねて持っていても、願い出ることができません。理由は二つです。一つめに、イタリアの国民が日本のミクロネーションの騎士になることは、常識に照らして、そもそも場違いです。二つめに、イタリアの 1951 年法律第 178 号第 8 条は、称号を使う者も罰し、授けたのが国外であっても及ぶとしています。称号を受けて使ったイタリアの国民が、同条がヌスクァマに及ぶいちばん現実の道です。この限りで、同条が及ぶおそれは減りますが、なくなりはしません（適法性の説明「日本の外の法令」）。旅行などで日本に短く滞在しているだけの人は、日本に住んでいる人に当たりません。

良識の前提

2026-11-22 から、叙任は、願い出る人が、称号を遊びとして扱う良識ある人であることを前提とします。この前提は、称号を創作の中でだけ使い、次の決まりを守ることを指します。

  • 称号を、この国の中でだけ使う（利用規約「称号の扱い」、王国基本法第八条）。
  • 称号を、実在の称号・叙勲・団体の記章であるかのように示さない。
  • 称号を、履歴書・論文・名刺・公的な書類・商取引・広告に書かない。
  • 称号を売らず、称号を使って金銭や物品を集めない。
  • 称号を、人をだますために使わない。

これらは、利用規約の「称号の扱い」「してはいけないこと」「悪意がないことと、法令を守ること」と王国基本法第八条の決まりを、称号の使い方として並べたものです。2026-11-22 から、願い出る人は、様式でこの前提に印を付けます。願い出た人が書いたことや訂正のリンク先から、この前提に当たらないことがはっきり分かったときは、叙任しません（「断ること」）。叙任した後に分かったときは、「辞退と取り消し」の定めにより、叙任を取り消します。取り消すときは、願い出の issue に、当たらなかった決まりだけを短く書き、人を評しません。本人の求めがあれば、その issue を削除します。

願い出の手順

サイトを配信する Vercel や、願い出を保管する GitHub が、置かれたものを AI のモデルの学習に使うことがあるため、個人情報が心配な方は、願い出ないでください。この利用は、個人情報の取り扱いに書いてあります。

  1. 叙任の願い出の様式で issue を開く。
  2. 訂正への公開のリンクと、何を誤りどう正したかを書く。
  3. 誓いのすべてに印を付ける。

願い出た人が同意するのは、願い出の日の版の規程です。その版は、公開のリポジトリの履歴で確かめられます。

本名・住所・所属・連絡先は書きません。

運営者が確かめること

  • リンク先が公開されていて、訂正であると読めること。
  • 訂正したのが、願い出た人自身の誤りであると読めること。
  • 他人の個人情報や、他人を傷つける内容が含まれていないこと。
  • 様式の誓いのすべてに印があること。
  • 訂正のリンク先に、願い出た人が日本の外に住んでいることや、願い出のときに日本の外にいること、イタリアの国籍を持つこと、16 歳未満であることが、はっきり書かれていないこと。書かれていれば、本人に尋ね、願い出の条件に当たると確かめられなければ叙任しません。

運営者は、訂正の中身が正しいかどうかを判断しません。判断するのは、訂正があったことだけです。

願い出の issue が開かれたり直されたりすると、自動の確認が、様式の誓いの印と、訂正へのリンクが開けるかどうかを確かめ、結果を issue にコメントします。自動の確認は何も決めません。叙任を決めるのは運営者です。

確かめないこと

運営者は、国籍・住んでいる国・年齢・本名を確かめません。身分証も求めません。ヌスクァマは国籍を与えません。騎士は国民ではありません。年齢・住んでいる国・願い出のときにいる国・イタリアの国籍を持たないことは、様式の誓いへの印による本人の申告で受けます。ただし、訂正のリンク先にはっきり書かれていることは、見落としません。本人として扱うのは、願い出た GitHub のアカウントです。願い出の条件に当たらなかったことが分かったときは、名簿から名を外します。16 歳未満の人の願い出だったときは、求めがなくても、その issue も削除します。

断ること

次の場合は叙任しません。

  • 誤りの訂正ではないもの（宣伝、自己紹介、他人の誤りの指摘など）。
  • 確かめられないもの（非公開のもの、リンクが開けないもの）。
  • 利用規約の「してはいけないこと」に当たるもの。
  • 願い出の条件（年齢・住んでいる国・願い出のときにいる国・国籍）に当たらないことが、訂正のリンク先からはっきり読めるもの。
  • 2026-11-22 から、「良識の前提」に当たらないことが、願い出た人が書いたことや訂正のリンク先からはっきり読めるもの。

断るときは、決めた一文（「叙任の条件に当たりません。」）だけを issue に書き、人を評しません。本人の求めがあれば、その issue を削除します。

名簿

叙任した人は、騎士の名簿に、叙任の順に載せます。叙任したときは、運営者が願い出の issue に、名簿の行へのリンクを添えたコメントを書き、issue を「完了」として閉じます。位は「騎士」の一つだけで、上下はありません（王国基本法第七条）。名簿には、騎士をアカウント名だけで記します。呼ぶときは「騎士 アカウント名」とし、ほかの呼び名や飾りの語を足しません。

辞退と取り消し

騎士は、いつでも名簿からの辞退を求めることができます。理由は要りません。辞退すると、名簿から名を外します。運営者は、騎士が称号をこの国の外（利用規約「称号の扱い」）で使ったとき（王国基本法第八条）や、利用規約に反したときに、叙任を取り消すことがあります。取り消したときは、名簿から名を外します。王国は誤りを消さないことを旨としますが、人の名は別です。名簿から外した名は、本人の求めがない限り、取り消しの記録にも残しません。

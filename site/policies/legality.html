無何有騎士王国ヌスクァマ

これは創作であり、遊びです。ヌスクァマは国家ではなく、いかなる実在の国家・王室・騎士団・叙勲・称号とも関係がありません。ここで授ける称号に、法的な効力はありません。

適法性の説明

最終更新：2026-11-08。

この頁の位置づけ

この頁は、ヌスクァマが法令に触れないと運営者が考える理由を、法令ごとに並べたものです。それぞれの法令について、当てはまるために要る事柄（要件）と、ヌスクァマの事実を並べ、要件に当たる事実がないことを示します。あわせて、その事実を保つための決めが、どの規程のどこにあるかを示します。

この頁は、運営者の理解を書いたもので、法的な助言でも保証でもありません。弁護士の確認は受けていません。条文は要旨で書いており、文言そのものではありません。要旨は、2026-11-08 に e-Gov 法令 API から取り寄せた現行の条文と突き合わせました。突き合わせた条は、各節の見出しに挙げています。取り寄せは、GitHub Actions から e-Gov 法令 API（v1）に問い合わせて行いました。原文はe-Gov 法令検索で確かめられます。法令や事実が変われば、この頁を改めます。

運営の姿勢

ヌスクァマに悪意はありません。人をだますことも、誰かを害することも、目的にしていません。運営者は、日本の法令と、使っているサービスの規約を守って運営します。法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します。適法かどうか迷う事柄は、行わないほうを選びます。この姿勢は、利用規約「悪意がないことと、法令を守ること」で約束しています。

前提となる事実

以下の説明は、次の事実の上に立っています。どれも、公開のリポジトリとサイトで確かめられます。

  • 領土を持たず、どの土地の領有も主張しない。
  • 国民・政府・軍・警察を持たない。
  • 通貨・旅券・身分証・証明書を発行しない。
  • お金や品物を受け取らない。何も売らず、寄付を受けず、広告を出さない。
  • 勲章・徽章・制服などの物を作らず、配らない。
  • 称号は、創作の中の言葉として、リポジトリとサイトと、王がこの国を紹介するために自ら書いた記事や投稿（README「ほかの場所」に挙げたもの）の中でだけ使う。
  • 扱う個人情報は、GitHub のアカウント名と、本人が公開した訂正へのリンクと、本人が書いた説明だけ。リンクの先から本名や所属が分かることがあり、そのことを様式で知らせている。
  • 16 歳未満の人と、住んでいる国の法令が私人の授ける騎士の称号を禁じている人の願い出は受けない。
  • 国籍・年齢・住んでいる国・本名を確かめる書類を取らない。年齢・住んでいる国・願い出のときにいる国は、様式の誓いによる本人の申告で受ける。
  • どの頁も、創作であり、実在の何とも関係がないと断っている。

法令ごとの整理

内乱に関する罪（刑法第77条）

  • 要件の要旨：国の統治機構を破壊し、またはその領土で国権を排除して権力を行使し、その他憲法の定める統治の基本秩序を壊乱することを目的として、暴動をすること。暴動の意味（多数の人が結び付いて暴行や脅迫をし、一地方の平穏を害する程度に至ること）は、条文にはなく、一般的な解釈による。
  • ヌスクァマの事実：領土を持たず、日本や他国の統治や権力を排除しようとしない。人の集まりも、暴行も脅迫もない。王国基本法第九条は、剣を抜かないこと、争いを言葉と証拠で決めることを定めている。
  • 当てはまらない理由：目的も暴動もない。
  • 保つための決め：利用規約「ヌスクァマとは何か」、王国基本法第一条・第九条。

称号の詐称と標章の使用（軽犯罪法第1条第15号）

  • 要件の要旨：官公職・位階勲等・学位その他法令で定められた称号、または外国におけるこれらに準ずるものを、偽って名乗ること（詐称）。または、資格がないのに、法令で定められた制服・勲章・記章その他の標章や、それらに似せて作った物を用いること。
  • ヌスクァマの事実：騎士王・騎士は、どの国の法令にも定められていない、創作の中の言葉である。ヌスクァマは国家ではないので、その称号は「外国におけるこれらに準ずるもの」にも当たらない。勲章・記章・制服などの物は作らず、国章は実在のどの記章にも似せていない。
  • 当てはまらない理由：名乗っているのは法令上の称号ではなく、物の標章も用いていない。さらに、法令上の称号と誤認させる使い方そのものを禁じている。
  • 保つための決め：利用規約「称号の扱い」（法令上の称号と誤認させる使い方の禁止、履歴書・名刺・公的な書類への記載の禁止）、王国基本法第八条、名称と権利「国章」。

公文書・旅券に関わる罪（刑法第155条、旅券法第23条）

  • 要件の要旨：行使の目的で、公務所や公務員の作るべき文書を偽造すること（刑法第155条）。他人名義の旅券を使うこと、偽造された旅券を行使の目的で譲り渡し、受け取り、所持することなど（旅券法第23条）。
  • ヌスクァマの事実：旅券・身分証・証明書・任命書の類を作らない。叙任は、名簿にアカウント名を載せるだけで、書面を発行しない。
  • 当てはまらない理由：偽造の対象となる文書を作っていない。
  • 保つための決め：利用規約「ヌスクァマとは何か」（旅券・国籍を持たない）、叙任の規程「叙任とは」（書面や物を発行しない）。

詐欺（刑法第246条）

  • 要件の要旨：人を欺いて財物を交付させること。または、その方法で、財産上不法の利益を得ること。
  • ヌスクァマの事実：お金も品物も受け取らない。称号を売らず、寄付を受けず、叙任は無償である。
  • 当てはまらない理由：財物や利益の移転がない。
  • 保つための決め：利用規約「費用」、王国基本法第六条、騎士王の十則の五。ヌスクァマの名で有料の称号を授けると称する者がいても関係がない、と利用規約に書いている。

取引に関わる法令（特定商取引法第2条、景品表示法第5条、消費者契約法第2条・第8条・第10条）

  • 要件の要旨：販売業者や役務提供事業者が、訪問・通信・電話勧誘などで商品や役務を売ること（特定商取引法）。事業者が、自分の供給する商品や役務の取引について、著しく優良または有利と誤認させる表示をすること（景品表示法）。事業として契約の当事者となる者と消費者との契約で、事業者の損害賠償の責任の全部を免除する条項などは無効になる（消費者契約法）。
  • ヌスクァマの事実：何も売らず、広告を出さず、事業を営まない。
  • 当てはまらない理由：これらの法令が前提とする取引がない。消費者契約法については、万一適用される場合に備えて、免責事項「責任」で、同法が適用されるときは免責の文を適用せず、軽過失による損害を含めて責任を負うと書いている。同法第8条第1項は責任の全部の免除を、第3項は軽過失に限ることを明らかにしない一部の免除を、無効とする。免責事項は、そのどちらにも当たらない。
  • 保つための決め：利用規約「費用」。

通貨と支払いの手段（資金決済法第3条）

  • 要件の要旨：金額や数量に応ずる対価を得て、証票や電子的な記録として発行され、代価の弁済や物品・役務の請求に使える前払式支払手段を発行すること。
  • ヌスクァマの事実：通貨・点数・引換券・電子的な価値のどれも発行しない。
  • 当てはまらない理由：発行も取り扱いもない。
  • 保つための決め：利用規約「ヌスクァマとは何か」（通貨を持たない）。

商標と表示（商標法第25条、不正競争防止法第2条第1項第1号・第2号）

  • 要件の要旨：商標権者が専有する、指定商品や指定役務についての登録商標の使用を、権利なく行うこと（商標法）。需要者の間に広く知られた他人の商品等表示と同一または類似の表示を使い、混同を生じさせること。他人の著名な商品等表示と同一または類似のものを、自分の商品等表示として使うこと（不正競争防止法）。
  • ヌスクァマの事実：営業をしない。名前は、ラテン語の一般語と古典の語に由来し、他人の商品や団体の表示を借りていない。国章は自作である。
  • 当てはまらない理由：営業上の使用がなく、他人の表示を使っていない。
  • 保つための決め：名称と権利、免責事項「実在のものとの関係」。

著作権（著作権法第21条・第23条）

  • 要件の要旨：著作者が専有する複製や公衆送信（送信可能化を含む）を、許諾なく行うこと。
  • ヌスクァマの事実：文と国章は、運営者が Claude Code で書かせ、確かめたものである。他人の著作物を写していない。『ユートピア』や『荘子』は、名前の由来として挙げているだけで、本文を写していない。どちらも著作権の保護期間をとうに過ぎている。
  • 当てはまらない理由：他人の著作物を複製していない。
  • 保つための決め：名称と権利、削除・訂正・辞退の求め（権利を侵す内容の削除の求め）。

個人情報（個人情報保護法第17条・第18条・第27条・第28条）

  • 要件の要旨：個人情報を扱う事業者は、利用の目的をできる限り特定し、その達成に必要な範囲を超えて扱わない。第三者に個人データを渡すとき、外国にある第三者に渡すときは、あらかじめ本人の同意を得るなどの決まりを守る。
  • ヌスクァマの事実：扱うのは、GitHub のアカウント名・訂正へのリンク・本人が書いた説明だけで、本名・住所・連絡先は求めない。利用の目的、公開されること、米国の GitHub と Vercel で扱われることを示し、願い出の様式で本人が同意する。名簿からの辞退と削除に、いつでも無償で応じる。
  • 当てはまらない理由：法令が求める扱いを、規程と様式で満たしている。
  • 項ごとの対応：個人情報保護法第17条・第18条・第20条・第21条・第22条・第23条・第25条・第26条・第27条・第28条・第32条・第33条・第34条・第35条・第36条・第37条・第38条・第40条と、同法施行令第10条、同法施行規則第7条・第8条・第10条・第17条の義務を、項ごとに規程の文と結んだ表を verification/duties.json に置いた。条文は 2026-11-08 に e-Gov から取り寄せて読んだ。検査が、文の実在と、条文の見張りとの対応を確かめる。
  • 保つための決め：個人情報の取り扱い、叙任の規程「辞退と取り消し」、叙任の願い出の様式の誓い。

名誉と信用（刑法第230条・第231条、民法第709条）

  • 要件の要旨：公然と事実を摘示して人の名誉を毀損すること。事実を摘示しなくても、公然と人を侮辱すること。故意または過失で、他人の権利や法律上保護される利益を侵害し、損害を生じさせること。
  • ヌスクァマの事実：特定の人を論じない。騎士の名簿は、本人の願い出と同意によるアカウント名だけを載せる。叙任を断るときも、理由は短く書くだけで、人を評しない。
  • 当てはまらない理由：人の名誉を傷つける表示がない。
  • 他人が書いたもの：issue には、願い出た人や求めた人が文を書く。他人の名誉や個人情報を害する記載が書かれたときは、判断の前にただちに外す。
  • 保つための決め：利用規約「してはいけないこと」（中傷・嫌がらせの禁止）、削除・訂正・辞退の求め「求めを受けた後」。

国際法での立場

  • 要件の要旨：国際法では、国家であるには、一般に、永続的な住民、明確な領域、政府、他の国と関係を結ぶ能力の四つがそろうことが求められる（1933 年のモンテビデオ条約第 1 条）。同条約第 3 条は、国家の政治的な存在は他の国の承認によらない、とする。この条約は米州の国々のあいだのもので、日本は当事国ではないが、国家の要件を示すものとして広く引かれる。条約の文は Avalon Project（イェール大学）の英文で、当事国は寄託者である米州機構（OAS）の一覧で、2026-11-08 に確かめた。
  • ヌスクァマの事実：住民・領域・政府を持たず、主権も領有も主張しない。どの国の領域も、どの国にも属さない土地や海の上の構造物も主張しない。どの国とも外交の関係を結ばず、国家としての承認も求めない。旅券も国籍も出さない。
  • 当てはまらない理由：四つの要件のどれも満たさず、満たそうともしない。ヌスクァマは国際法上の国家ではなく、国際法上の権利や義務を持つものでもない。どの国の主権も、領土の一体性も、国際法上の地位も損なわない。
  • 保つための決め：利用規約「ヌスクァマとは何か」、免責事項「創作であること」、王国基本法第一条。

国籍（国籍法第11条）

  • 要件の要旨：日本の国民は、自分の望みによって外国の国籍を取ったときは、日本の国籍を失う。
  • ヌスクァマの事実：ヌスクァマは外国ではなく、国籍を与えない。騎士は国民ではない。叙任は、名簿にアカウント名を載せるだけである。
  • 当てはまらない理由：取る「外国の国籍」がないので、叙任によって誰の国籍も変わらない。どの国の国籍法についても同じである。
  • 保つための決め：利用規約「ヌスクァマとは何か」（国籍を持たない）、叙任の規程「確かめないこと」（国籍を与えない）。

日本の外の法令

  • ヌスクァマは日本から運営する、非営利の創作である。どの国でも、事業も取引もせず、金銭や有料の会員の勧誘もしない。
  • 国によっては、自国の栄典や称号を偽って名乗ることを禁じている。ヌスクァマは、称号をこの国の外で使うことと、実在の称号や叙勲と誤認させる使い方を禁じている（王国基本法第八条、利用規約「称号の扱い」）。
  • 例として、イタリアの 1951 年法律第 178 号第 8 条は、私人や団体が、名称を問わず騎士の称号などを授けることを禁じている。同条は、そうした称号を使う者も罰し、授けたのが国外であっても及ぶ、としている。条文は、イタリアの公式の法令データベース Normattiva で、2026-11-08 に確かめた。こうした国に住む人の願い出は受けない（叙任の規程「願い出ることができる人」）。住んでいる国は本人の申告で受け、確かめない（叙任の規程「確かめないこと」）。
  • EU の一般データ保護規則（GDPR）は、EU の外の者にも、EU にいる人に役務を提供するときなどに及ぶことがある。及ぶ場合に備えて、扱う情報を本人が公開するものに限り、同意で受け、開示・訂正・削除の求めに無償で応じている（個人情報の取り扱い）。GDPR 第 3 条第 2 項は、EU の外の管理者にも、EU にいる人に、支払いの有無を問わず物や役務を提供するときなどに及ぶ、としている。条文は EUR-Lex で、2026-11-08 に確かめた。
  • 米国カリフォルニア州の消費者プライバシー法（CCPA）は、営利の事業者を対象とする。ヌスクァマは営利の事業をしないので、当たらないと考える。カリフォルニア州司法長官の CCPA の頁で、営利の事業者が対象で、非営利の団体には一般に及ばないことを、2026-11-08 に確かめた。州の法令の頁は、機械からの取得を止める仕組みがあるので、読んでいない。
  • そのほかの国の法令については、運営者は個別に確かめていない。
  • 2026-11-22 から、願い出は日本に住み、願い出のときに日本にいる人に限る。国籍は問わない。日本の外の法令は国ごとに確かめきれないので、及ぶおそれのある国に住む人を、はじめから受けない。外国の法令には、そこにいる人に及ぶものがあるので、旅行・出張・留学などで日本の外にいるあいだの願い出も受けない（叙任の規程「願い出ることができる人」）。
  • 本人の申告は確かめないが、訂正のリンク先に日本の外に住むことや 16 歳未満であることがはっきり書かれていれば、本人に尋ね、条件に当たると確かめられなければ叙任しない。気づくことができた事柄を見落とさないためである（叙任の規程「運営者が確かめること」）。

使っているサービスの規約

  • GitHub：リポジトリと issue は、GitHub の利用規約に沿って使う。禁じられた内容を置かない。
  • Vercel：サイトは Vercel の Hobby プランで配信している。Hobby プランは、個人的で非営利の利用に限られる（Vercel の Fair Use Guidelines、2026-11-08 に確かめた）。ヌスクァマは非営利で、この条件に合う。

審査の方法と残る危険

この頁の結論は、次の五つの方法で確かめました。

  1. 要件の論理式：罪や義務は、要件がすべてそろったときにだけ成り立つ。要件を A₁ ∧ A₂ ∧ … ∧ Aₙ と置けば、事実が一つの Aᵢ を否定するだけで全体が偽になる。法令ごとに、どの要件をどの文が否定しているかを verification/legal-matrix.json に並べ、検査がその文の実在を確かめる。
  2. 網羅：行う者（運営者・願い出る人・騎士・読む人・第三者）と、行い（公開する・受け付ける・名簿に載せる・称号を使う・情報を保つ・国外に及ぶ）の組を、verification/legal-matrix.json にすべて並べた。どの組も、この頁のどれかの項が扱うか、起こらない組である。
  3. 無矛盾：同じ事柄を、頁ごとに違って書いていないかを突き合わせた。「この国の中」の範囲が頁ごとに違っていたので、利用規約の一か所で定め、ほかの頁はそこを指すように改めた（王の正誤表 6）。
  4. 故障の木：前提の事実が崩れる道を並べ、起こりやすさと重さを 1 から 3 で見積もり、その積で順を付けた。数は運営者の見積もりで、順を付けるためだけのもの。
  5. 壊して確かめる：固めた文を一つずつ書き換え、検査が落ちることを見た。

審査は一度きりではありません。この頁が拠る条文と GitHub の規約は、週に一度、e-Gov 法令 API と GitHub から取り寄せ、記録した値と比べています（tools/statutes.js）。違えば、新旧の条文の差分を付けた提案が自動で作られます。提案は PR か、PR を一押しで作るリンクを添えた issue です。運営者は差分を読んでこの頁を確かめ、ラベル「記す」を付けます。そのときワークフローが、取り込んだ結果で検査を回し、通ったときだけ記します。取り寄せに失敗したときは issue が開きます。この頁が条文を挙げたのに、見張りの表にないときは、検査が落ちます。

管轄の合意の効き方

利用規約は、示談を優先したうえで、第一審の合意管轄裁判所を定めています。この定めがどこまで効くかを、ここに書きます。

  • 法令の要旨：当事者は、第一審に限り、合意で管轄裁判所を定めることができる。合意は、一定の法律関係に基づく訴えについて、書面か電磁的記録でしなければ効力を生じない（民事訴訟法第11条）。将来の消費者契約の紛争について国の裁判所を定める合意は、消費者の住所がある国の裁判所に訴えられるときなど、限られた場合にだけ効力を持つ（民事訴訟法第3条の7第5項）。
  • ヌスクァマの事実：叙任を願い出る人は、様式で利用規約への同意に印を付ける。その印は issue に残る。サイトやリポジトリを読むだけの人は、何にも印を付けない。
  • 効き方：様式で同意した人との間では、同意の記録が電磁的記録として残る。読むだけの人との間では、書面の合意がないので、管轄の合意は効力を生じないことがある。そのときは、法令の定める裁判所が管轄する。利用規約は、消費者や日本国外の人が、法令によって別の裁判所で訴える権利を奪わないと書いている。
  • 保つための決め：利用規約「準拠法と紛争」、叙任の願い出の様式の誓い。

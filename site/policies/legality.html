無何有騎士王国ヌスクァマ

これは創作であり、遊びです。ヌスクァマは国家ではなく、いかなる実在の国家・王室・騎士団・叙勲・称号とも関係がありません。ここで授ける称号に、法的な効力はありません。

適法性の説明

最終更新：2026-11-08。

この頁の位置づけ

この頁は、ヌスクァマが法令に触れないと運営者が考える理由を、法令ごとに並べたものです。それぞれの法令について、当てはまるために要る事柄（要件）と、ヌスクァマの事実を並べ、要件に当たる事実がないことを示します。あわせて、その事実を保つための決めが、どの規程のどこにあるかを示します。

この頁は、運営者の理解を書いたもので、法的な助言でも保証でもありません。弁護士の確認は受けていません。条文は要旨で書いており、文言そのものではありません。原文はe-Gov 法令検索で確かめられます。法令や事実が変われば、この頁を改めます。

運営の姿勢

ヌスクァマに悪意はありません。人をだますことも、誰かを害することも、目的にしていません。運営者は、日本の法令と、使っているサービスの規約を守って運営します。法令に触れるおそれが分かったときは、その部分を止めてから確かめ、直します。適法かどうか迷う事柄は、行わないほうを選びます。この姿勢は、利用規約「悪意がないことと、法令を守ること」で約束しています。

前提となる事実

以下の説明は、次の事実の上に立っています。どれも、公開のリポジトリとサイトで確かめられます。

  • 領土を持たず、どの土地の領有も主張しない。
  • 国民・政府・軍・警察を持たない。
  • 通貨・旅券・身分証・証明書を発行しない。
  • お金や品物を受け取らない。何も売らず、寄付を受けず、広告を出さない。
  • 勲章・徽章・制服などの物を作らず、配らない。
  • 称号は、創作の中の言葉として、リポジトリとサイトの中でだけ使う。
  • 扱う個人情報は、GitHub のアカウント名と、本人が公開した訂正へのリンクと、本人が書いた説明だけ。
  • どの頁も、創作であり、実在の何とも関係がないと断っている。

法令ごとの整理

内乱に関する罪（刑法第77条）

  • 要件の要旨：国の統治機構を壊す、またはその領土で国の権力を排除して権力を行使するなどの目的で、暴動をすること。暴動とは、多数の人が結び付いて暴行や脅迫をし、一地方の平穏を害する程度に至ることをいう。
  • ヌスクァマの事実：領土を持たず、日本や他国の統治や権力を排除しようとしない。人の集まりも、暴行も脅迫もない。王国基本法第九条は、剣を抜かないこと、争いを言葉と証拠で決めることを定めている。
  • 当てはまらない理由：目的も暴動もない。
  • 保つための決め：利用規約「ヌスクァマとは何か」、王国基本法第一条・第九条。

称号の詐称と標章の使用（軽犯罪法第1条第15号）

  • 要件の要旨：官公職・位階勲等・学位その他法令で定められた称号、または外国でそれらに当たるものを偽って名乗ること。または、資格がないのに、法令で定められた制服・勲章・記章その他の標章や、それらに似せて作った物を用いること。
  • ヌスクァマの事実：騎士王・騎士は、どの国の法令にも定められていない、創作の中の言葉である。ヌスクァマは国家ではないので、「外国における称号」にも当たらない。勲章・記章・制服などの物は作らず、国章は実在のどの記章にも似せていない。
  • 当てはまらない理由：名乗っているのは法令上の称号ではなく、物の標章も用いていない。さらに、法令上の称号と誤認させる使い方そのものを禁じている。
  • 保つための決め：利用規約「称号の扱い」（法令上の称号と誤認させる使い方の禁止、履歴書・名刺・公的な書類への記載の禁止）、王国基本法第八条、名称と権利「国章」。

公文書・旅券に関わる罪（刑法の文書偽造の罪、旅券法）

  • 要件の要旨：公務所や公務員の作るべき文書や、旅券を、偽って作ったり使ったりすること。
  • ヌスクァマの事実：旅券・身分証・証明書・任命書の類を作らない。叙任は、名簿にアカウント名を載せるだけで、書面を発行しない。
  • 当てはまらない理由：偽造の対象となる文書を作っていない。
  • 保つための決め：利用規約「ヌスクァマとは何か」（旅券・国籍を持たない）、叙任の規程「叙任とは」（書面や物を発行しない）。

詐欺と、お金を集めることに関わる法令（刑法第246条ほか）

  • 要件の要旨：人をだまして財物を交付させ、または財産上の利益を得ること。
  • ヌスクァマの事実：お金も品物も受け取らない。称号を売らず、寄付を受けず、叙任は無償である。
  • 当てはまらない理由：財物や利益の移転がない。
  • 保つための決め：利用規約「費用」、王国基本法第六条、騎士王の十則の五。ヌスクァマの名で有料の称号を授けると称する者がいても関係がない、と利用規約に書いている。

取引に関わる法令（特定商取引法、景品表示法、消費者契約法）

  • 要件の要旨：事業として商品や役務を売り、表示し、または消費者と契約すること。
  • ヌスクァマの事実：何も売らず、広告を出さず、事業を営まない。
  • 当てはまらない理由：これらの法令が前提とする取引がない。消費者契約法については、万一適用される場合に備えて、免責事項「責任」に、同法の定める責任を負うと書いている。
  • 保つための決め：利用規約「費用」。

通貨と支払いの手段（資金決済法）

  • 要件の要旨：前払いで使える支払いの手段や、資金の移動、それに当たる電子的な価値を発行し、または扱うこと。
  • ヌスクァマの事実：通貨・点数・引換券・電子的な価値のどれも発行しない。
  • 当てはまらない理由：発行も取り扱いもない。
  • 保つための決め：利用規約「ヌスクァマとは何か」（通貨を持たない）。

商標と表示（商標法、不正競争防止法）

  • 要件の要旨：他人の登録商標を、指定された商品や役務について使うこと。または、他人の周知・著名な商品等の表示と同じか似た表示を、営業の上で使うこと。
  • ヌスクァマの事実：営業をしない。名前は、ラテン語の一般語と古典の語に由来し、他人の商品や団体の表示を借りていない。国章は自作である。
  • 当てはまらない理由：営業上の使用がなく、他人の表示を使っていない。
  • 保つための決め：名称と権利、免責事項「実在のものとの関係」。

著作権（著作権法）

  • 要件の要旨：他人の著作物を、許諾なく複製し、公衆に送信するなどすること。
  • ヌスクァマの事実：文と国章は運営者の創作である。『ユートピア』や『荘子』は、名前の由来として挙げているだけで、本文を写していない。どちらも著作権の保護期間をとうに過ぎている。
  • 当てはまらない理由：他人の著作物を複製していない。
  • 保つための決め：名称と権利、削除・訂正・辞退の求め（権利を侵す内容の削除の求め）。

個人情報（個人情報保護法）

  • 要件の要旨：個人情報を扱う者は、利用の目的を示し、目的の外で使わず、第三者に渡すときや外国にある第三者に渡すときには本人の同意を得るなどの決まりを守ること。
  • ヌスクァマの事実：扱うのは、GitHub のアカウント名・訂正へのリンク・本人が書いた説明だけで、本名・住所・連絡先は求めない。利用の目的、公開されること、米国の GitHub と Vercel で扱われることを示し、願い出の様式で本人が同意する。名簿からの辞退と削除に、いつでも無償で応じる。
  • 当てはまらない理由：法令が求める扱いを、規程と様式で満たしている。
  • 保つための決め：個人情報の取り扱い、叙任の規程「辞退と取り消し」、叙任の願い出の様式の誓い。

名誉と信用（刑法第230条ほか、民法の不法行為）

  • 要件の要旨：公然と事実を示して人の名誉を傷つけること、侮辱すること、または不法に他人の権利を侵して損害を与えること。
  • ヌスクァマの事実：特定の人を論じない。騎士の名簿は、本人の願い出と同意によるアカウント名だけを載せる。叙任を断るときも、理由は短く書くだけで、人を評しない。
  • 当てはまらない理由：人の名誉を傷つける表示がない。
  • 保つための決め：利用規約「してはいけないこと」（中傷・嫌がらせの禁止）、削除・訂正・辞退の求め。

日本の外の法令

  • ヌスクァマは日本から運営する、非営利の創作である。どの国でも、事業も取引も募集もしない。
  • 国によっては、自国の栄典や称号を偽って名乗ることを禁じている。ヌスクァマは、称号を国の外で使うことと、実在の称号や叙勲と誤認させる使い方を禁じている（王国基本法第八条、利用規約「称号の扱い」）。
  • 日本の外の法令については、運営者は個別に確かめていない。

使っているサービスの規約

  • GitHub：リポジトリと issue は、GitHub の利用規約に沿って使う。禁じられた内容を置かない。
  • Vercel：サイトは Vercel の Hobby プランで配信している。Hobby プランは、個人的または非営利の利用に限られる。ヌスクァマは非営利で、この条件に合う。

  • 保つための決め：名称と権利、免責事項「実在のものとの関係」。

名誉と信用（刑法第230条・第231条・第233条、民法第709条）

  • 要件の要旨：公然と事実を摘示して人の名誉を毀損すること。事実を摘示しなくても、公然と人を侮辱すること。虚偽の風説の流布や偽計で、人の信用を毀損すること。故意または過失で、他人の権利や法律上保護される利益を侵害し、損害を生じさせること。
  • ヌスクァマの事実：特定の人を論じない。騎士の名簿は、本人の願い出と同意によるアカウント名だけを載せる。叙任を断るときも、理由は短く書くだけで、人を評しない。
  • 当てはまらない理由：人の名誉や信用を傷つける表示がない。
  • 他人が書いたもの：issue には、願い出た人や求めた人が文を書く。他人の名誉や個人情報を害する記載が書かれたときは、判断の前にただちに外す。
  • 保つための決め：利用規約「してはいけないこと」（中傷・嫌がらせの禁止）、削除・訂正・辞退の求め「求めを受けた後」。
  • 点検で足したこと（2026-11-12）：issue は、不特定の人が読む GitHub の上に書かれる。この送信は、情報流通プラットフォーム対処法第2条第1号の特定電気通信に当たる。運営者が、その役務を提供する者（同条第4号）に当たるかは、設備を GitHub が持つので、条文からは決まらない。運営者は、当たるものとして扱う。その場合、他人の権利を侵す書き込みについて、送信を防ぐことが技術的にできて、侵害を知っていたか、知ることができたと認めるに足りる相当の理由があるときでなければ、賠償の責めを負わない（情報流通プラットフォーム対処法第3条第1項）。書き込みを外したことで書いた人に生じた損害は、必要な限度で外し、他人の権利が不当に侵害されていると信じるに足りる相当の理由があったときなどに限って、責めを負わない（同条第2項）。運営者は、個人情報の露出と名誉や信用を傷つける記載はただちに外して後で確かめ、ほかは同項第1号か第2号の道で外す。大規模特定電気通信役務提供者（同法第2条第14号）の義務は、指定を受けた者のものなので、運営者には及ばない。

# ほかのミクロネーションとの突き合わせ（2026-11-21）

> これは創作であり、遊びです。この記録は、創作の国ヌスクァマの決まりを、ほかのミクロネーションの決まりと並べて見直した記録です。ほかの国について何かを認めるものでも、否むものでもありません。

## この記録について

2026-11-21 に、利用者の求めで、よく知られたミクロネーションの憲法・基本法・称号の決まり・国民の決まり・サイトの規約を調べ、ヌスクァマの決まりと突き合わせました。
調べたのは Claude（Anthropic の言語モデル）です。
ヌスクァマは、ここに名を挙げるどの国とも関係がありません。

## 読んだもの

作業の場所からは、それぞれの国のサイトに届きません。
全文を読めたのは、Liberland が GitHub で公開している憲法の案と法令（CC0）だけです。
ほかの国については、検索の結果の要約に出た文を見ました。要約の文は、元の頁とそのとおり同じかを確かめていません。
そのため、この記録は、ほかの国についての事実を言い切りません。ヌスクァマの決まりを足すことだけに使いました。

## 足したもの

| 足したもの | ほかの国で見たこと | 置いた所 |
| --- | --- | --- |
| 住む所・仕事・移住・査証・在留の資格を与えないこと。国籍を与えないことは、もともと利用規約「ヌスクァマとは何か」にあり、同じ節にまとめて書いた | 遊びの国の「国民」に、本当の移住の道を求める人が多く申し込んだと伝えられた例（Ladonia、2002 年の報道。中身は確かめていません） | [利用規約](../policies/terms.md)「与えないもの」 |
| 騎士であることも、訪れることも、どの国の法令の務め（税・兵役・裁判の手続き）も免れさせないこと | 国を名乗った者が税の支払いを命じられ、のちに国を閉じたと伝えられた例（Hutt River、2017 年の判決と 2020 年の解散の報道。中身は確かめていません） | 利用規約「与えないもの」 |
| 運営者のほかに、この国を代表する者（大使・領事・代理人）を置かず、代表と称する者は関係がないこと | ある国の名誉の領事を名乗った者が、偽の大使館を開いたとして逮捕されたと伝えられた例（2025 年の報道と、その国が出したとされる声明。中身は確かめていません） | 利用規約「与えないもの」。[交流の規程](../policies/exchange.md)は、もともと大使・領事を置かないと書く |
| ヌスクァマが出したと称する旅券・身分証・証明・叙任状・勲章・車の番号札は、ヌスクァマのものではないこと | ミクロネーションの名の旅券が、本物の旅券のように使われたと伝えられた例（いくつかの報道。中身は確かめていません） | 利用規約「与えないもの」 |
| 訪れる人の五つの自由（誤る、正す、訪れる人のままでいる、信じない、去る） | 遊びの心で書いた権利の箇条（Užupis の憲法、Outer Baldonia の憲章） | [国の仕組み](../INSTITUTIONS.md)「訪れる人の五つの自由」 |

どれも、読む人や騎士に不利になる変更ではないので、公開の日に効力を生じます（利用規約「変更と終了」）。
五つの自由の文は、ほかの国の文を写さず、ヌスクァマの言葉で書きました。一つめの誤る自由は、Užupis の憲法に伝えられる一条に近い考えです。二つめの正す自由と、王に誤りを消す自由がないことは、基本法第五条と十則の六から来ています。

## もともとあったもの

突き合わせで、次のことはヌスクァマにすでにあると分かりました。

- 国家としての承認を求めないこと（免責事項、利用規約）。
- 叙任が無償であること（基本法第六条）。称号に法的な効力がなく、売らず、寄付も受けないこと（利用規約「称号の扱い」「費用」）。
- 称号を使う場所を限り、反したときは名簿から名を外すこと（基本法第八条、叙任の規程）。
- 旅券・通貨を持たないこと（基本法第一条）。身分証も出さないこと（利用規約「ヌスクァマとは何か」、適法性の説明）。
- 条約・同盟・承認の文書を結ばず、称号を授け合わないこと（交流の規程）。
- 決まりを改める手順と、削らない条（基本法第十条、国の仕組み「改めるとき」）。
- 王位が一代限りで、継ぐ者を置かないこと（基本法第二条、建国の宣言）。
- 凍結と解散の手順（国の仕組み「凍結」「解散」）。調べた範囲では、解散の手順を前もって書いた国は見つかりませんでした。
- 暦と祝日（暦の頁）。

## 足さなかったもの

| 見たこと | 足さなかった理由 |
| --- | --- |
| 国民の登録、電子の居住、身分証 | ヌスクァマは国民を持たず（基本法第一条）、国籍を与えない（利用規約「ヌスクァマとは何か」、国の仕組み「人口と呼び名」）。登録を置くと、名簿のほかに個人の記録が増える |
| 国の通貨や記念の硬貨 | 通貨を出さない（基本法第一条）。資金決済法に近づく道を作らない（適法性の説明） |
| 国歌 | 曲と詞の権利が絡む。国旗と国章は、長方形と多角形だけで描いてある |
| 議会・選挙・国民投票 | 決めるのは王一人で、騎士に務めを負わせない（国の仕組み「決め方」） |
| 位の上下や昇進の待ちの年数 | 位は「騎士」の一つだけで、上下を設けない（基本法第七条） |
| 叙任を、ほかの国の称号と授け合うこと | 交流の規程が禁じている |

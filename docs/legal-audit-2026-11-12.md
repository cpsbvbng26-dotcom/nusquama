# 法令の点検の記録（2026-11-12）

> これは創作であり、遊びです。この記録は、創作の国ヌスクァマの規程が法令についてどう書いているかを、運営者の側で点検したものです。

## この記録について

2026-11-12 に、ヌスクァマの規程が法令について書いているところを、条ごとに点検しました。
点検は、Claude（Anthropic の言語モデル）が、運営者の求めで行いました。
対象は、[適法性の説明](../policies/legality.md)、[利用規約](../policies/terms.md)、[免責事項](../policies/disclaimer.md)、[個人情報の取り扱い](../policies/privacy.md)、[削除・訂正・辞退の求め](../policies/requests.md)、[叙任の規程](../policies/knighting.md)、[名称と権利](../policies/names.md)、[交流の規程](../policies/exchange.md)、[国の仕組み](../INSTITUTIONS.md)、願い出・求め・誤りの知らせの様式、`verification` の条文と一次資料の表です。
この記録は、運営者の側の理解を書いたものです。読む人への法的な助言ではありません。

## 点検のしかた

条文は、作業の場所から e-Gov にも EUR-Lex にも届かないので、リポジトリの取り寄せの仕組みで読みました。
日本の条文は、Actions の「条文と規約の見張り」を枝 `claude/legal-audit-1112-fetch` で走らせ、e-Gov 法令 API（v1）から取り寄せました。
外国の文は、Actions の「一次資料の取り寄せ」を同じ枝で走らせました。
取り寄せた文は、`verification/statutes-texts.json` と `verification/sources-raw.json` にあります。
GitHub の利用規約は、`verification/statutes.json` に記したコミットの原文を、GitHub から直に読みました。
法令の文を、記憶から書いてはいません。取り寄せられなかった文に拠る結論は、確かめていないものとして扱いました。

一つの記載ごとに、次の三つを見ました。

1. 条・項・号の番号が合っているか。
2. 引用が一字一句同じか。
3. 引いた条が、頁の拠るところを本当に定めているか。

結論ごとに、要件を一つずつ分け、リポジトリの事実（集めているもの、公開しているもの、誰に届くか、お金、広告、配信の場）と照らしました。

判定は、次の五つのどれかです。

| 判定 | 意味 |
| --- | --- |
| 誤り | 条の番号や引用が違う。または、引いた条の文の上で結論が誤っている |
| 根拠不足 | 結論が、分析の届くところより先へ行っている |
| 漏れ | 当てはまりうる法令や義務を、検討していなかった |
| 表現 | 確かさを強く言いすぎている。または、読み違えを招く |
| 問題なし | 確かめた |
